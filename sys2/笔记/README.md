# 计算机系统 II · 笔记（`sys2/笔记/`）

「计算机系统 II」（第 1–4 讲讲义署卢立 Li Lu，第 5–6 讲 PDF 标题页署 Haifeng Liu）各讲笔记的 **Markdown 原件**与讲义原页配图。
本目录是笔记的「家」：改内容改这里的文件，站点构建时会由 `网站/prepare.py` 复制到 `网站/.docs/`（**不要**直接改生成副本）。

## 阅读与使用

- 课前：先读一篇的「本讲速览」，再按小节顺序读正文，最后做「课前自测」；
- 自测题与正文小节之间用**标题锚点链接**互跳（写法与 GitHub / VS Code 预览一致）；
- 标注约定：`【讲义】` = 幻灯片原文或直接提炼；`(p.x)` / `(s.x)` = **PDF 页码** / **PPTX 幻灯片页码**；`待确认` = 讲义未写明或存在疑点之处（不做臆断）；
- 第 3、4 讲内容有重叠（第 4 讲是第 3 讲的加详），两讲以**所在讲次**分别成文，口径差异在该篇的「待确认」里注明；
- 第 5 讲正文按新 PDF（76 页，§5.1–§5.3）编排，只有附录 A 用旧版 PPTX 的 `(s.x)` 页码；第 6 讲全篇用 PDF 页码 `(p.x)`。

## 注意事项

- 本目录的**笔记**会发布到笔记网站（本文件 `README.md` 除外：MkDocs 会把 `README.md` 当作目录的 `index.md`，
  故已在 `网站/prepare.py` 的 `SKIP_FILES` 中排除，站点上的入口仍是 `00_索引.md`）；
  新增 / 改名 / 调整标题后，须同步 `网站/mkdocs.yml` 的 `nav`，再跑 `python 网站/build.py`；
- 讲义原件（`../*.pdf`）**只读**，且不入库；
- 提交前自检：`python3 ADS/assets/check_md_links.py sys2` 与 `python3 ADS/assets/check_md_anchors.py sys2`（退出码 0 为通过）。
