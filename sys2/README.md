## 3. 资料层级与标注

1. **讲义 PDF 是主标准**：硬件部分 `lec/lec01`–`lec06`；OS 部分 `lec/00-0_course_syllabus.pdf`、`lec/00-1_computerarchitecture.pdf`、`lec/01_intro.pdf`。硬件第 5、6 讲以 PDF 为准，旧版 `lec05.pptx` 只用于硬件第 5 讲附录 A 的 Tomasulo 例题。
2. **`class/` 是补充资料**：与讲义重复的内容标为“重复·重点”；`classN` 有而 `lecN` 没有的内容标为“补充”。不得用补充资料覆盖讲义口径。
3. 页码约定：`(p.x)` 指 **PDF 页码**；OS 第 0 讲合并两份 PDF，写成 `(00-0 p.x)` / `(00-1 p.x)`；`(s.x)` 只指旧版硬件第 5 讲 PPTX 的幻灯片页码，三者不要混用。
4. 来源标注：
   - `【讲义】`：幻灯片原文或直接提炼；
   - `【朋辈辅学·classN】`：从朋辈辅学资料补入的内容；
   - `待确认`：讲义未写明、编号不一致或存在疑点之处。
5. 讲义小节号沿用讲义自身编号（硬件第 1 讲 §1.x … 硬件第 6 讲 §6.x；OS 部分按 PDF 页码与主题分节），与教材章节号可能不同。

## 4. 笔记与题目整理约定

### 4.1 笔记

- 硬件部分一篇为 `hardware-0N_第0N讲_<主题>.md`，OS 部分一篇为 `os-0N_第0N讲_<主题>.md`；结构固定：**本讲速览 → 按小节展开（带 PDF 页码）→ 听课重点与易混点 → 课前自测 → 来源、页码对照与待确认**。
- 配图放 `笔记/assets/`：硬件用 `fig_p<PDF 页码>_<主题>.png`；OS 用 `fig_os000_*` / `fig_os001_*` / `fig_os01_*`，避免不同 PDF 的页码相撞；旧版硬件第 5 讲的 `fig_s*.png` 作为历史配图保留，但不与 PDF 页码混用。
- 自测题的每条问题带本讲小节锚点；篇末设「关联知识点」，链接本讲、跨讲或原始资料。
- 硬件第 3、4 讲内容重叠，按所在讲次分别成文；口径差异写在硬件第 4 讲「待确认」中，不擅自合并。
- 新增或改写内容后，同步更新 `笔记/00_索引.md`；新增 / 改名 / 调整标题后，同步 `网站/mkdocs.yml` 的 `nav`。

### 4.2 补入 `class/` 资料

1. 先判断该知识点对应哪一讲 / 哪一节，不把整份辅学材料直接粘贴进笔记。
2. 在目标笔记中新增独立小节，例如 `## 朋辈辅学补充（classN）`；每条开头注明 `【朋辈辅学·classN】` 与页码。
3. 与讲义重复处标注“重复·重点”，只写精炼提醒；辅学独有内容标注“补充”，并说明它补在哪个讲义概念之后。
4. 若内容无法归入现有讲次，不要硬塞；先在 `笔记/00_索引.md` 的待确认中记录，再与本人确认是否新建笔记及是否加入站点导航。
5. `class/` 原件只读，不复制、不改名、不裁剪。

### 4.3 练习题

- 计算机组成与流水线题目放 `计算机组成题目/`；操作系统题目放 `操作系统题目/`。
- 每个题组一个 Markdown 文件：题干按题号在前，参考答案放在文末「参考答案（点击展开）」一节，用 `<details>` 折叠。
- 题干、代码块、表格与计算过程必须与原始题目一致；原始截图不随稿保留，若数字有歧义，在文首写“还原注记”，不要猜。
- 题目整理稿不发布到笔记网站。

## 5. 修改后的自检

在仓库根目录执行：

```bash
python3 ADS/assets/check_md_links.py sys2     # 相对路径能否打开
python3 ADS/assets/check_md_anchors.py sys2   # 标题锚点能否指到
python3 网站/build.py                         # 汇集 → 构建 → 站点自检
```

`网站/.docs/`、`网站/site/`、`网站/.cache/` 都是生成目录，**不要直接修改**。自检不通过时先修笔记原件，不要改生成副本。

## 6. 发布与版本控制

- 笔记网站只发布 `笔记/` 下的 Markdown、配图与可复现脚本；本文件、`笔记/README.md`、讲义原件、辅学资料和题目整理稿都不发布。
- `lec/`、`class/` 与其他原始 PDF / PPTX 不入库；仓库采用白名单式 `.gitignore`，Markdown 与图片默认放行，提交前仍应按根目录 `README.md` 的规则核对范围。
- 讲义原件与朋辈辅学原件只读；任何整理都另存到 `笔记/` 或题目目录中。
