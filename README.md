## 2. 笔记结构约定

每门课在 `<课程>/笔记/` 下组织：

```text
笔记/
├── 00_索引.md              # 文件列表、一句话摘要、建议阅读顺序、待确认事项
├── 01_<讲次>_<主题>.md
├── 02_<讲次>_<主题>.md
└── assets/                 # 配图，命名 fig_p<页码>_<主题>.png
```

- 每篇笔记结构固定：**速览 → 核心概念 → 关键公式与算法 → 例子 → 听课重点与易混点 → 课前自测 → 来源**；
- 图片一律放对应 `assets/`，在 Markdown 中用**相对路径**引用，不内嵌 base64；
- 标注约定：
  - `【讲义】`：讲义 / 幻灯片原文或直接提炼；
  - `(p.x)`：讲义页码；
  - `待确认`：讲义未写明或存在疑点之处，不做臆断；
  - 图注中注明来源页；标注「自绘」的图不是讲义截图。

## 3. 内容免责

- 笔记由 AI 依据讲义整理，用于**课前预习与课后复习**，只做提炼与串讲，不添加讲义之外的结论；
- 公式、算法细节、编码与页码以讲义和教材为准，可能有遗漏；
- 发现与讲义不符之处，以讲义为准并欢迎提 issue。

## 4. 版本控制约定

`.gitignore` 采用**白名单模式**（`*` 排除一切，再按需放行），只追踪：

- Markdown：`*.md`
- 图片：`*.png`、`*.jpg`、`*.jpeg`、`*.gif`、`*.bmp`、`*.webp`、`*.svg`、`*.tif(f)`、`*.heic`、`*.ico`

显式排除：`/大物实验/`（含个人信息）、`AGENTS.md`（本地规则文件）。
其余文件（PDF / PPT / DOC(X) / 代码 / 数据 / 压缩包 / 缓存 / 环境变量）默认不入库。
如需临时追踪某个被忽略的文件，使用 `git add -f <路径>`。
