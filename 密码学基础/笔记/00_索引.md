## 1. 这份笔记覆盖什么

- **速查表提纲**的定位是**期中的 all-in-one 速查纸**（资料自述 “期中 all in one paper”），覆盖私人密钥密码学的**前半段**：
  > 导论与原则 → 完美保密 / OTP → 单向函数 → 伪随机生成器 → 多消息安全 → IND-CPA → 伪随机函数 / 置换 → MAC
- **课程笔记**是按**课次**记的课堂笔记，覆盖整门课到公钥加密为止：
  > Lec1 基础概念 → Lec2 完美保密 → Lec3 计算安全 → Lec4 EAV/PRG → Lec5 多消息 → Lec6 CPA → Lec7 PRF/PRP/MAC → Lec8 构造 MAC → Lec9 CCA & AE → Lec10 Hash → Lec11 硬假设 → Lec12 密钥交换 → Lec13 公钥加密（**到此为止**：笔记末尾的「注」说 25 秋冬没讲数字签名，期末也只考到 PKE）
- 本目录的 **01–07 篇**以**主题**为骨架（导论 → 完美保密 → OWF/PRG → 多消息/CPA → PRF/PRP → MAC → Hash），**08–11 篇**是后半段（CCA/AE、数论与硬假设、密钥交换、公钥加密），**13、14 两篇**是考试相关材料（范围 / 回忆卷 / 期中试卷转录），**12 篇**是第一次作业。
