## 4. 建议阅读顺序

1. [`01`](01_导论与密码学原则.md)：先把「定义 / 假设 / 证明」三要素立住。
2. [`02`](02_完美保密与一次性密码本.md)：第一个精确的安全定义，以及它的代价。
3. [`03`](03_单向函数与伪随机生成器.md)：进入计算安全，理解 OWF、CI 与 PRG。
4. [`04`](04_多消息安全与IND-CPA.md)：从一次加密走到多消息与 IND-CPA。
5. [`05`](05_伪随机函数与伪随机置换.md) → [`06`](06_消息认证码MAC.md) → [`07`](07_哈希函数与Merkle-Damgård结构.md)：从 PRF 到完整性。
6. [`08`](08_CCA安全与认证加密.md)：把机密性与完整性合起来。
7. [`12`](12_习题一_OTP缺陷与OWF-PRG关系.md)：用 02/03 的定义做题。
8. 公钥部分：[`09`](09_数论基础与密码学硬假设.md) → [`10`](10_密钥交换与Diffie-Hellman.md) → [`11`](11_公钥加密与ElGamal.md)。
9. 考前：[`13`](13_考试范围与复习要点.md) → [`14`](14_期中试卷_25秋冬.md)。
