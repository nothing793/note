## 资料来源（按优先级）

1. **教材（权威口径）**：Katz & Lindell, *Introduction to Modern Cryptography*, Chapman & Hall/CRC,
   **2007 年第 1 版** —— `../Introduction_to_Modern_Cryptography.pdf`。
   **2026-10-19 起**，笔记中的定义、定理/构造编号与结论均以该版为准；教材与课程资料冲突时**以教材为准**。
   第 1 版与常见的第 3 版编号差别很大（例如 OWF 是 Definition 6.1、PRG 是 Definition 3.15、
   随机预言模型在第 13 章），各篇对应关系见 [`00_索引.md` §1.1](00_索引.md#11-教材版本与章节映射2007-年第-1-版)。
2. **课程资料**：一份速查表提纲 ＋ 一份按课次记录的课程笔记（Lec1–Lec13）。清单与链接写在
   `../readme.md`，原件导出为 `../数据安全与密码学基础.zip`。
   教材没有、课程资料独有的内容（如 worst-case / weak OWF、Needham–Schroeder、ECBC-MAC、
   Hash-and-MAC、理想预言机模型等）一律标为「**课程补充**」，不冒充教材内容。
3. 上述 PDF、zip 与 `../readme.md` 均为**只读引用**（不修改、不移动、不重命名、不入库）。
   按用户约定，笔记正文**不标注资料代号**，只用中性表述（「资料」「课程笔记」「速查表提纲」「教材」）。

## 标注约定

| 标记 | 含义 |
|---|---|
| 🙈 | **资料自己标出的「需要证明」**之处：只写「要证什么 + 提示」，不代替给出证明（**例外**：用户 2026-10-12 指定补全的 [`02` §3](02_完美保密与一次性密码本.md#3-两个定义等价) 等价性证明与 [`02` §4.3](02_完美保密与一次性密码本.md#43-证明密钥下界整理者补全) 密钥下界证明，已标为「整理者补全」） |
| `待确认` | 资料没说清、前后矛盾、公式渲染损坏或转录残缺处；**不做臆断**，原样标出 |
| `教材对照` | 给出 Katz & Lindell《Introduction to Modern Cryptography》（**2007 年第 1 版**）的章节 / 定义 / 定理编号；均已按用户上传的 PDF 核对（第 1 版与第 3 版编号差别很大，旧稿的第 3 版编号已全部替换） |
| `整理者核对 / 整理者按语 / 整理者作答` | 整理者自己的一致性核算、推导或作答，**不是**资料原文、也**不是**官方答案 |
