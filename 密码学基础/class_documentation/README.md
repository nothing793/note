## 使用约定

1. `origin/` 中的转写只读引用，不另外改写措辞。`2026-11-2.md` 保留收到时的文件名，没有重命名。
2. 需要修订课程内容时只改 `class_documentation.md`，不要回头改原始转写；摘要与原件冲突时，以原件为准并注明。
3. 摘要中的记号以 `class_documentation.md` 的「术语与格式规范」为准；课堂没有展开或录音不清的地方标「待确认」，不凭印象补写。
4. 课堂举例（中途岛、外包公司、地摊眼镜等）只作直观解释，不当作形式定义。
