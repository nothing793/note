# class_documentation

「密码学基础」课堂记录与整理稿。授课教师张聪，2026 年秋冬学期。

## 目录用途

这里保存课堂录音的转写、按日期拆分的原件，以及在此基础上整理出的课程摘要。`笔记/01`–`04` 的内容以本目录的整理稿为主要来源；教材只用于核对定义、补足课堂没有展开的细节。

## 文件说明

| 路径 | 内容 | 使用方式 |
|---|---|---|
| `class_documentation.md` | 整理后的课程记录：术语约定、笔记格式建议，以及 6 次课的主题摘要 | 先读这一份，用来把握主线与考点 |
| `origin.md` | 课堂录音的完整转写，按时间顺序排列 | 查原话、例子和推导细节时使用；保持原样，不直接改写 |
| `origin/` | 从 `origin.md` 按授课日期拆出的 6 个文件 | 按次查阅，内容与 `origin.md` 对应段落一致 |

## 使用约定

1. `origin.md` 是原始转写，只读引用；`origin/` 中的文件由它按日期切分而来，不另外改写措辞。
2. 需要修订课程内容时，先改 `class_documentation.md`，再按同一日期边界重新拆分 `origin.md`，避免摘要与原件各说各话。
3. 摘要中的记号以 `class_documentation.md` 的「术语与格式规范」为准；出现「待核」或课堂没有展开的地方，查 `origin/` 对应日期，仍不清楚就标注，不凭印象补写。
4. 课堂举例（中途岛、外包公司、地摊眼镜等）只作直观解释，不当作形式定义。
