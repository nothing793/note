## 目录用途

这里保存课堂转写、按日期拆分的原件，以及在此基础上整理出的课程摘要。`笔记/01`–`04` 与 `05` 的 PRF 部分已按本目录的整理稿校准；`05` 的 PRP、GGM 与工作模式按 11-16 课堂记录重写；`06` 已按 11-23 课堂记录重写主体，CBC-MAC 等后续内容暂按教材与早期笔记放在延伸节。教材只用于核对定义、补足课堂没有展开的细节。

## 使用约定

1. `origin/` 中的转写只读引用，不另外改写措辞。`2026-11-2.md` 保留收到时的文件名，没有重命名；`2026-11-23.md` 是结构化的课程记录，保持原样。
2. 需要修订课程内容时只改 `class_documentation.md`，不要回头改原始转写；摘要与原件冲突时，以原件为准并注明。
3. 摘要中的记号以 `class_documentation.md` 的「术语与格式规范」为准；课堂没有展开或录音不清的地方标「待确认」，不凭印象补写。
4. 课堂举例（中途岛、外包公司、地摊眼镜等）只作直观解释，不当作形式定义。
