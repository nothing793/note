# 二、术语与格式规范

## 1. 常用术语

- **PPT**：Probabilistic Polynomial-Time，概率多项式时间。
- **OWF**：One-Way Function，单向函数。
- **PRG**：Pseudorandom Generator，伪随机数生成器。
- **CI**：Computational Indistinguishability，计算不可区分。
- **EAV**：Eavesdropping security，窃听安全。
- **IND-CPA**：Indistinguishability under Chosen-Plaintext Attack。
- **LR-CPA**：Left-or-Right CPA game。
- **OTP**：One-Time Pad，一次一密。
- **negligible**：可忽略函数。
- **super-polynomial**：超多项式。

## 2. 笔记格式建议

- 定义用引用块或加粗；
- 公式用 LaTeX；
- reduction 证明建议画表：

| 项目 | 内容 |
|---|---|
| 外部游戏 | reduction 与真实挑战者玩的游戏 |
| 内部游戏 | reduction 模拟给攻击者 A 的游戏 |
| reduction 输入 | 外部挑战者给的内容 |
| reduction 输出 | 如何把 A 的输出转化为外部游戏的猜测 |
| 模拟一致性 | A 看到的分布是否与真实游戏完全一致 |
| 概率损失 | 如 \(\delta \to \delta/2\) |

# 三、整理后的课程记录

## 9.14 导论课：密码学基本框架与可证明安全

**本节目标**：建立密码学的基本问题、密码系统六要素、算法属性、安全定义的必要性，以及可证明安全的三个元素。

**课程要求**：点名约 10%，作业约 10%，期中约 50%，期末按安排；有 bonus；鼓励随时打断提问；考试尽量多写；不要作弊。教师采用中文解释、英文板书。

**密码学的基本问题**：最 fundamental 的应用是：Alice 和 Bob 在不安全信道上通信，攻击者可窃听全部信息，如何保证消息安全。核心观察是 Alice 和 Bob 必须共享攻击者没有的 secret key。

**密码系统六要素**：三个空间 \(M,C,K\) 与三个算法：
1. 密钥生成 \(\mathrm{Gen}\)；
2. 加密 \(\mathrm{Enc}\)；
3. 解密 \(\mathrm{Dec}\)。

**算法属性**：
- \(\mathrm{Gen}\) 应为随机算法；否则攻击者可运行确定性算法得到密钥。
- \(\mathrm{Dec}\) 通常为确定性算法，保证功能性。
- \(\mathrm{Enc}\) 应优先采用随机算法；确定性加密会带来频率分析等问题。

**Kerckhoffs 原则**：算法公开，安全性只依赖密钥保密。算法公开后经全球攻击者检验仍安全，才是好的安全算法。

**正确性形式化**：希望解密结果等于原文。完美正确性要求对每个密钥、每个消息都成立；也可用概率形式表达“绝大多数密钥/消息正确”的松弛版本。

**传统安全 vs 可证明安全**：
- 传统安全：“没人攻破就安全”，依赖反馈和权威背书，缺陷明显。
- 可证明安全三要素：**Assumption（假设/基石）**、**Definition（安全刻画）**、**Reduction（归约）**。
- 归约直觉：如果你能攻破我的系统，我就能用你的攻击解决公认困难问题；因为大家相信该困难问题，所以必须相信我的系统。

**应用例子**：
- MPC：双方在不泄露各自输入的情况下计算函数，如交友匹配、扑克牌协议；需注意参与者是否诚实。
- ZKP：不泄露秘密而证明知道某事实，如 GPA 证明、色盲与两个球。ZKP 的妙处是：在未定义“knowledge”的情况下定义了“zero knowledge”，核心是“没有获得额外信息”。

**关键提醒**：真正要保护的是 message，密钥只是必要条件；assumption 只是共识，可能被底层击碎，要选得好且好用。

## 9.21 香农与完美安全

**本节目标**：给出正确、安全、高效的加密目标；先追求不依赖计算假设的无条件安全。

**第一次尝试：只要求密钥不泄露**：必要但不充分。反例：恒等加密 \(c=m\)，密钥没泄露但明文全暴露。

**第二次尝试：密文不泄露任何信息**：太强，不可实现。至少长度会泄露。

**香农的折中**：允许攻击者拥有关于明文的先验知识，但要求看到密文后对明文的认知不比之前更多。

**香农安全定义**：对任意明文分布 \(D\)、任意 \(m,c\)，若 \(\Pr[C=c]>0\)，有
\[
\Pr[M=m\mid C=c]=\Pr[M=m].
\]
其中 \(M\sim D\)，\(C=\mathrm{Enc}(K,M)\)，\(K\sim\mathrm{Gen}()\)。

**完美安全定义**：对任意 \(m_1,m_2\)，由它们导出的密文分布完全相同：
\[
\{\mathrm{Enc}(K,m_1)\}\equiv \{\mathrm{Enc}(K,m_2)\}.
\]

**等价性证明要点**：
- 完美安全 \(\Rightarrow\) 香农安全：展开条件概率，利用 \(\sum_{k:\mathrm{Enc}(k,m)=c}\Pr[K=k]\) 与 \(m\) 无关。
- 香农安全 \(\Rightarrow\) 完美安全：因香农安全对任意分布成立，可选只在 \(m_1,m_2\) 上有质量的分布，代入推出两个密文分布相同。

**一次一密 OTP**：\(K,M,C\in\{0,1\}^n\)，\(K\) 均匀随机，\(\mathrm{Enc}(K,M)=K\oplus M\)，\(\mathrm{Dec}(K,C)=K\oplus C\)。对任意 \(m_1,m_2,c\)，存在唯一密钥使加密结果为 \(c\)，概率均为 \(1/2^n\)，故完美安全。

**为什么移位密码不安全**：密钥空间小且密钥重复使用；OTP 要求密钥均匀随机、与消息等长、每次只用一次。

**香农定理**：完美安全要求 \(|K|\ge |M|\)。直觉：若密钥空间小于明文空间，则存在某密文不能由某明文加密得到，从而两个明文导出的密文分布不同，违反完美安全。

**代价**：密钥不可压缩，效率差；下节课引入计算安全与假设。

## 9.28 从无条件安全到单向函数

**本节目标**：从“无条件安全但低效”退一步，引入 assumption，刻画 PPT 攻击者，并从 P≠NP 信仰推出单向函数。

**攻击者刻画**：
- 无条件安全下攻击者算力无穷，大数分解也等价于 1+1=2，因此必须限制攻击者能力。
- 选择多项式时间：看增长速率而非绝对数值；现实中高效算法多集中在低次多项式；多项式时间在语言转换和常数次组合下封闭。
- 攻击者本质是算法；形式化为确定性图灵机加随机带，运行时间上界 \(n^C\)，即 **PPT 攻击者**。

**困难问题来源**：
- 停机问题真困难但不好用。
- 计算机人的信仰是 \(P\ne NP\)；基于 NP 完全问题构造假设。
- 要找“攻击者在多项式时间内解不了”的问题，并用于构造加密。

**从加密必要条件推出单向性**：
- 加密需要：正确性；给定 \(k,m\) 易算 \(c\)；仅给 \(c\) 难反推 \(k\) 或 \(m\)。
- 这体现单向性：正向好算，反向难算。

**单向函数 OWF**：
- **worst-case OWF**：易于计算；不存在 PPT 攻击者能还原所有 \(x\)。与“NP 不在 BPP 中”关系很近，但太弱：攻击者能还原绝大多数点，仍无法用于加密。
- **strong OWF**：存在可忽略函数 \(\mathrm{negl}\)，使任何 PPT 攻击者成功还原概率 \(\le \mathrm{negl}(n)\)。这是理想目标，但现实中难直接达到。
- **weak OWF**：任何 PPT 攻击者成功概率不超过 \(1-1/\mathrm{poly}(n)\)，即失败比例不可忽略。允许还原很多，但必须有一部分搞不定。

**乘法构造 weak OWF**：\(f(x,y)=x\cdot y\)，排除 \(x=1\) 或 \(y=1\)。当 \(x,y\) 为大素数时，反推对应大数分解；随机取到素数的比例不可忽略，因此可作 weak OWF 的直觉构造。严格归约课上未展开。

**weak 到 strong 的扩张**：取 \(N\) 个 weak OWF \(f_1,\dots,f_N\)，定义
\[
F(x)=f_1(x_1)\|f_2(x_2)\|\cdots\|f_N(x_N).
\]
只要有一个分量搞不定，整体就搞不定，从而得到 strong OWF。这说明 weak 与 strong 在构造意义上可转化。

## 10.12 计算不可区分、安全参数与 PRG

**本节目标**：补充 OWF 性质，说明 OWF 不能直接构造加密；定义计算不可区分与 PRG；用 PRG 构造 EAV 安全加密。

**OWF 的两个重要性质**：
1. OWF 只保护“全部信息”，不保护“部分信息”。攻击者可以还原一部分比特，只要不能找到完整原像，仍可能是 OWF。
2. OWF 输出不需要看起来随机，可以有结构；甚至某些比特固定，只要整体满足单向性。

**直接使用 OWF 构造加密的问题**：无法解密；且 OWF 可能泄露消息全部信息，只保护密钥不可还原。因此需要“看起来随机”的 mask。

**目标蓝图**：需要一种东西，具有：
1. 不可区分性：看起来随机；
2. 长度扩张：输出比输入长。

**计算不可区分 CI**：两个分布族 \(\{X_n\},\{Y_n\}\) 是 CI 的，若存在可忽略函数 \(\mathrm{negl}\)，使对任何 PPT 攻击者 \(A\)，
\[
\left|\Pr[A(X_n)=1]-\Pr[A(Y_n)=1]\right|\le \mathrm{negl}(n).
\]
注意：不要求概率等于 \(1/2\)，只看差；negligible 只在 \(n\) 足够大时有意义；CI 具有传递性，可用于 hybrid argument。

**安全参数**：用 \(\lambda\) 或 \(n\) 表示；密钥生成输入 \(1^\lambda\)；AES-256 中 256 是安全参数，表示现阶段已知最好攻击复杂度至少 \(2^{256}\)。分布不再固定，而是由安全参数索引的分布族。

**PRG 定义**：\(G:\{0,1\}^n\to\{0,1\}^{L(n)}\)，其中 \(L(n)>n\) 为多项式，且
\[
G(U_n)\approx_c U_{L(n)}.
\]
两个条件：长度扩张；输出与均匀分布计算不可区分。

**用 PRG 构造加密**：
- 密钥 \(sk\in\{0,1\}^n\)；
- 加密 \(c=m\oplus G(sk)\)；
- 解密 \(m=c\oplus G(sk)\)。

正确性显然；密钥比消息短；消息空间扩张到 \(L(n)\)。

**EAV 安全游戏**：挑战者生成 \(sk\)，攻击者选等长 \(M_0,M_1\)，挑战者投 \(b\)，返回 \(\mathrm{Enc}(sk,M_b)\)，攻击者猜 \(b'\)。优势为 \(|\Pr[A\text{赢}]-1/2|\)，可忽略则 EAV 安全。

**Reduction 直觉**：若 A 能以优势 \(\delta\) 攻破 EAV，则 reduction 能以约 \(\delta/2\) 优势攻破 PRG。外部是 PRG 挑战者，内部模拟 EAV 给 A；\(B=0\) 时用 PRG 样本作 mask，\(B=1\) 时是 OTP。A 猜对则 reduction 猜“伪随机”，否则猜“随机”。

## 10.19 PRG 构造加密、EAV 归约与 reuse 问题

**本节目标**：完整理解 PRG 构造加密的归约；发现 EAV 只支持一次加密，提出 reuse 需求。

**PRG 加密回顾**：\(c=m\oplus G(sk)\)。与 OTP 只差“真随机串换成伪随机串”。

**三要素**：
- Assumption：\(G\) 是 PRG；
- Definition：EAV 安全；
- Reduction：若 A 攻破 EAV，则 reduction 攻破 PRG。

**EAV 游戏复习**：公开参数；挑战者选 \(sk\)；A 选 \(M_0,M_1\)；挑战者投 \(b\)，返回 \(\mathrm{Enc}(sk,M_b)\)；A 输出 \(b'\)。优势为 \(|\Pr[A\text{赢}]-1/2|\)。

**归约细节**：
- 外部 PRG 挑战者给 reduction 一个样本；\(B=0\) 时为 \(G(x)\)，\(B=1\) 时为均匀随机串。
- 内部 reduction 模拟 EAV：A 选 \(M_0,M_1\) 后，reduction 用外部样本作为 mask 加密，返回给 A。
- A 输出 \(b'\)；reduction 若 \(b'=b\) 则猜外部是伪随机，否则猜随机。
- 概率：\(\Pr[\text{reduction 赢}]=1/2+\delta/2\)。损失为 \(\delta\to\delta/2\)，但不可忽略性保持。

**reuse 需求**：现实中希望同一密钥可加密多条消息。定义应改为：对任意消息序列 \(M0_1,\dots,M0_q\) 与 \(M1_1,\dots,M1_q\)，在同一 \(sk\) 下导出的联合分布计算不可区分。

**确定性加密为何不能 reuse**：攻击者可选第一个序列前两块相同、第二个序列前两块不同；确定性加密下密文是否相同一眼可辨，因此能赢游戏。结论：**确定性加密无法实现 multiple-message security**。这补上了第一节课“加密算法应随机”的理由。

**直接加随机数为何不行**：若简单把随机数 \(r\) 放入密文或与 mask 组合，可能使攻击者获得种子相关信息；PRG 只保证“完全不知道种子时输出伪随机”，不保证泄露部分信息后仍伪随机。因此需要更强工具：即使一部分信息泄露，剩余 mask 仍伪随机【具体构造待核】。

## 10.26 IND-CPA、LR-CPA 与 hybrid argument

**本节目标**：定义 IND-CPA，说明其合理性；证明 IND-CPA 与 LR-CPA 等价；用 hybrid argument 证明 IND-CPA 能包住 multiple-message security。

**IND-CPA 五阶段**：
1. 初始化：挑战者公开 public parameter；
2. Phase 1：攻击者可任意询问加密，消息自选；
3. Challenge：攻击者选等长 \(M_0^*,M_1^*\)，可与 Phase 1 询问强相关；
4. 挑战者投 \(b\)，返回 \(\mathrm{Enc}(sk,M_b^*)\)；
5. Phase 2：攻击者可继续询问；
6. Guess：攻击者输出 \(b'\)。

**为什么允许选择明文**：现实中攻击者可诱导用户加密特定消息。中途岛战役中，美军散布“中途岛缺水”的假消息，日军电文出现“AF is short of water”，从而确定 AF 指中途岛。这说明 IND-CPA 的 Phase 1/2 并不过分。

**IND-CPA 的 high-level 作用**：即使加密同一明文，不同随机数下密文也必须看起来完全不同；否则攻击者可通过 Phase 1 询问区分。

**LR-CPA**：挑战者先选 \(sk\) 和 \(b\)；攻击者交互式发送 \(M0_i,M1_i\)，挑战者返回 \(\mathrm{Enc}(sk,M_{b,i})\)；攻击者最后猜 \(b'\)。LR-CPA 是动态策略，强于静态 multiple-message 游戏。

**等价性证明方向**：要证 IND-CPA 安全 \(\Rightarrow\) LR-CPA 安全；逆否为：若 A 攻破 LR-CPA，则 reduction 攻破 IND-CPA。

**归约模拟**：
- 外部：reduction 与 IND-CPA 挑战者玩；
- 内部：reduction 扮演 LR-CPA 挑战者与 A 玩；
- Phase 1/2 中 A 询问 \(M\) 时，reduction 把 \(M0=M1=M\) 发给外部挑战者，拿回 \(\mathrm{Enc}(sk,M)\)；
- Challenge 时把 A 的 \(M0^*,M1^*\) 直接发给外部挑战者；
- A 输出 \(b'\)，reduction 直接输出 \(b'\)。若 A 赢，reduction 赢，优势不损失。

**核心难点**：LR-CPA 中 A 可多次询问，而 IND-CPA 挑战者只给一次挑战密文。解决办法是 **hybrid argument**：
- 定义 Game Left（全答左边）、Game 1（第 1 个答右边，其余左边）、……、Game Right（全答右边）。
- 相邻 hybrid 只差一个位置，可用一次 IND-CPA 挑战来证明不可区分；
- 由 CI 传递性，Game Left 与 Game Right 不可区分，即 multiple-message security 得证。
- 直观：金主只给“1 块钱”，但可玩很多次不同 hybrid 游戏，“分期付款”式完成证明。

**结论**：IND-CPA 与 LR-CPA 等价；LR-CPA 显然包住 multiple-message security；因此 IND-CPA 满足 reuse 需求，是第二阶段的好定义。下节课将升级 PRG，构造满足 IND-CPA 的加密方案。
