## 2. 基本定义

- **近似比**【讲义定义】：算法产出的解代价 $C$ 与最优解（optimal solution）代价 $C^*$ 满足

$$C\le\rho(n)\,C^*\quad(\text{对任意规模为 } n \text{ 的输入}) \tag{1}$$

  这样的算法叫 $\rho(n)$-近似算法。（一般写作 $\max(C/C^*,C^*/C)$，以适应最大/最小两类问题。）
- **近似方案（approximation scheme）**：不仅接受问题实例（instance），还接受精度参数（accuracy parameter） $\varepsilon>0$；对任意固定的 $\varepsilon$，它是 $(1+\varepsilon)$-近似算法。
- **PTAS**（多项式时间近似方案）：对任意固定的 $\varepsilon>0$，运行时间是输入规模（input size） $n$ 的多项式。
- **FPTAS**（完全多项式时间近似方案）：讲义讲稿备注——"fully"指对 $\dfrac1\varepsilon$ 与 $n$ **都是多项式级**的。

## 3. 装箱问题（Bin Packing）

**问题**：$N$ 个物品（item），尺寸 $0<S_i\le1$，装进容量（capacity）为 1 的箱子，**用最少的箱子**。该问题是 **NP 难**的。

【讲义】的 7 件物品例子：$S_i=0.2,0.5,0.4,0.7,0.1,0.3,0.8$，最优装箱用 **3** 个箱子（$(0.8,0.2)$、$(0.7,0.3)$、$(0.1,0.5,0.4)$）。

### 3.1 Next Fit

```text
读入 item1；此后每读入 item2：能放进当前箱子就放，否则新开一个箱子。
```

> **【定理】** 设最优需要 $M$ 个箱子，则 Next Fit 从不超过 $2M-1$ 个；且存在序列使它真的用到 $2M-1$ 个。

**证明思路**【讲义】：若 Next Fit 用了 $2M$（或 $2M+1$）个箱子，则相邻两箱的尺寸和满足
$$S(B_1)+S(B_2)>1,\quad S(B_3)+S(B_4)>1,\ \dots,\quad S(B_{2M-1})+S(B_{2M})>1$$
于是所有物品的总尺寸 $>M$，而最优解至少要"总尺寸/1"个箱子——即至少 $M+1$ 个，矛盾。

### 3.2 First Fit、Best Fit 及家族

- **First Fit**：扫描**第一个装得下**的箱子，否则开新箱；可用 $O(N\log N)$ 实现。
  > **【定理】** First Fit 从不超过 $17M/10$ 个箱子；存在用到 $17(M-1)/10$ 的序列。
- **Best Fit**：放进**最"紧"**（剩余空间最小）的能容纳它的箱子；$T=O(N\log N)$、箱子数 $\le1.7M$。
- 讲稿备注提到同族还有 **Worst Fit**（装进最不满的箱子）、**Almost Worst Fit**、**Any Fit**，都是 $1.7$ 倍级别的界。
- 【讲义】用同一个 7 物品例子对比三种算法的装箱结果。
- **另一个"很难"的例子**：\#$\left(\tfrac17+\varepsilon\right)$ 类物品 6 个、$\left(\tfrac13+\varepsilon\right)$ 类 6 个、$\left(\tfrac12+\varepsilon\right)$ 类 6 个（$\varepsilon=0.001$）——**最优只需要 6 个箱子，而三种在线算法（online algorithm）都要 10 个**。逐箱手算见 [§10.1](#101-讨论题-14discussion-14三种在线装箱算法在这个例子上各用几个箱子)。

### 3.3 在线算法 vs 离线算法

- **在线（on-line）**：处理完一个物品、给出决定后**不能反悔**；你永远不知道输入何时结束。
  > **【定理】** 存在输入，使**任何**在线装箱算法至少用到最优箱数的 $5/3$ 倍。
- **离线（off-line）**：可以先看完所有物品再决定。
  - 思路：**先把物品按尺寸非增（non-increasing）排序（sorting）**，再用 First/Best Fit ⇒ **First Fit Decreasing / Best Fit Decreasing**；
  > **【定理】** FFD 从不超过 $11M/9+6/9$ 个箱子；存在用到 $11M/9+6/9$ 的序列。

## 4. 背包问题（Knapsack）

### 4.1 分数版（fractional）

- 容量 $M$，物品有重量（weight） $w_i$、利润（profit） $p_i$，取 $x_i\in[0,1]$ 的比例，最大化 $\sum p_ix_i$，约束（constraint） $\sum w_ix_i\le M$。
- 三个候选贪心准则（greedy criterion）：最大利润 / 最小重量 / **最大利润密度（profit density） $p_i/w_i$** ← 正确选择。
- 【讲义】例子：$n=3$，$M=20$，$(p_1,p_2,p_3)=(25,24,15)$，$(w_1,w_2,w_3)=(18,15,10)$ ⇒ 解 $(0,1,1/2)$，$P=31.5$。

### 4.2 0-1 版（每个 $x_i\in\{0,1\}$）——**NP 难**

- 【讲义】例子：$n=5$，$M=11$，$p=(1,6,18,22,28)$，$w=(1,2,5,6,7)$
  - 最优解 $(0,0,1,1,0)$：$18+22=40$（重量 $5+6=11$）；
  - 按利润密度贪心得 $(1,1,0,0,1)$：$1+6+28=35$。
- **近似比 = 2** 的证明（$p_{\max}$ 为最大利润）：

$$p_{\max}\le P_{\text{opt}}\le P_{\text{frac}},\qquad p_{\max}\le P_{\text{greedy}}\ \Longrightarrow\ P_{\text{opt}}\le P_{\text{greedy}}+p_{\max}\le2P_{\text{greedy}}$$

（第一式因为最优解一定装得下"利润最大的那件物品"。）

### 4.3 精确 DP 解与"利润太大"时的舍入（rounding）

- 定义 $W_{i,p}$ = 从 $\{1,\dots,i\}$ 中取总利润**恰好为 $p$** 的子集所需的最小重量，三种转移：取 $i$（$W_{i-1,p-p_i}+w_i$）、不取 $i$（$W_{i-1,p}$）、不可能（$\infty$）。规模 $i=1..n$、$p=1..n\,p_{\max}$，故 $O(n^2p_{\max})$。
- $p_{\max}$ 很大时【讲义】：**把利润向上舍入到较小范围**，得到 $(1+\varepsilon)$ 近似；$\varepsilon$ 是精度参数。
  > 研习室勘误（p.14）：缩放的**方向和不等号方向必须写清**。该站采用**向下取整**价值（$v'_i=\lfloor v_i/K\rfloor$，$K=\varepsilon v_{\max}/n$），
  > 证明的是**下界** $v(S)\ge(1-\varepsilon)\mathrm{OPT}$；只写"向上舍入得到 $(1+\varepsilon)$ 近似"不能说明近似的方向，也推不出对最优值的保证。
- 讲稿备注：**输入规模包含 $p_{\max}$ 的二进制（binary）编码（encoding）长度 $d$**，所以 $p_{\max}=O(2^d)$ 是指数级复杂度——这正是需要舍入的原因。
- 相关讨论：如果限制的是**重量**而不是利润，容量 DP 的复杂度会怎样？见 [§10.3](#103-讨论题物品重量都不超过-n2-时0-1-背包还是-np-难吗)。

## 5. K-中心问题（K-center）

- 输入：$n$ 个站点（site） $s_1,\dots,s_n$；选出 $K$ 个中心 $C$，使**每个站点到最近中心的距离的最大值**最小：
  $$\text{dist}(s_i,C)=\min_{c\in C}\text{dist}(s_i,c),\qquad r(C)=\max_i \text{dist}(s_i,C) \tag{2}$$
- **距离的度量（metric）要求**【讲义】：$\text{dist}(x,x)=0$（同一性）、$\text{dist}(x,y)=\text{dist}(y,x)$（对称性）、三角不等式（triangle inequality）。
- 候选中心**无限多**（平面上任意点都可以）。
- **第一次贪心（失败）**：先把第一个中心放在"单个中心的最优位置"，再逐步加中心以尽量减小覆盖半径（covering radius） ⇒ **可以任意差**（*arbitrarily bad*）。

### 5.1 Greedy-2r：给定 $r$ 的判定版（decision version）

```text
Centers Greedy-2r ( Sites S[ ], int n, int K, double r )
{   S' = S; C = ∅;
    while ( S' != ∅ ) {
        Select any s from S' and add it to C;
        Delete all s' from S' with dist(s', s) ≤ 2r;
    }
    if ( |C| ≤ K ) return C;
    else ERROR(No set of K centers with covering radius at most r);
}
```

> **【定理】** 若算法选出的中心多于 $K$ 个，则对任意大小不超过 $K$ 的集合 $C^*$，都有 $r(C^*)>r$。

- 由此可**二分搜索（binary search）** $r$：每次用 $2r$ 判定，得到 $r_0<r\le r_{\max}$，最终解的半径为 $2r_1$ ⇒ **2-近似**（删除半径为什么取 $2r$，见 [§10.2](#102-讨论题-15discussion-15删除半径为什么取-2r)）。
- 讲稿备注：若 $r$ 是**整数**，二分只有 $O(\log r)$ 步，是多项式时间。

### 5.2 Greedy-Kcenter：不需要预先知道 $r$

```text
Centers Greedy-Kcenter ( Sites S[ ], int n, int K )
{   C = ∅; Select any s from S and add it to C;
    while ( |C| < K ) { Select s from S with maximum dist(s, C); Add s to C; }
    return C;
}
```

> **【定理】** 该算法返回的 $K$ 个中心满足 $r(C)\le 2\,r(C^*)$——**2-近似**。

### 5.3 为什么不能做得更好

> **【定理】** 除非 P = NP，中心选择问题**不存在** $\rho<2$ 的 $\rho$-近似算法。

证明思路（【讲义】）：若有多项式时间的 $(2-\varepsilon)$-近似，就能多项式时间求解 **DOMINATING-SET**（NP 完全）；支配集问题有大小 $K$ 的解 ⇔ 存在 $K$ 个中心使 $r(C^*)=1$，而所有距离都是整数，$(2-\varepsilon)$-近似只能给出最优解。

## 6. 三个视角（【讲义】收尾页）

| 组合 | 含义 |
|---|---|
| **A+C** | 对**所有**实例都**最优** ⇒ 精确算法（NP 难问题里通常做不到多项式） |
| **A+B** | 精确且高效 ⇒ 只对**特殊实例类**可行 |
| **B+C** | 高效且对所有实例有质量保证 ⇒ **近似算法** |

【讲义】结论：即使 P = NP，也无法同时保证 A+B+C。

## 7. 听课重点与易混点

1. **近似比是"最坏情况（worst case）下的保证"**，与启发式的"平均表现好"不同（讲稿备注）。
2. **在线 vs 离线的分界线是"能否反悔"**：这直接决定了 $2$（或 $17/10$）与 $11/9$ 的界。
3. **装箱的界要记清对应算法**：NF $2M-1$、FF/BF $17M/10$、FFD $11M/9+6/9$、在线下界（lower bound） $5/3$。
4. **0-1 背包的贪心近似比是 2**，证明的关键是 $p_{\max}\le P_{\text{opt}}$ 与 $p_{\max}\le P_{\text{greedy}}$。
5. **$K$-中心的两个算法都是 2-近似**，但一个需要 $r$ 已知（用二分），一个用"最远点优先"。
6. **$\rho<2$ 的不可能性**来自支配集归约（reduction）——这是"近似比有下界"的标准范例。

### 10.1 讨论题 14（Discussion 14）：三种在线装箱算法在这个例子上各用几个箱子？

> 【讲义】*Discussion 14: Please show the results.*
>
> 题面（同一页）：$S_i$ 为六个 $1/7+\varepsilon$、六个 $1/3+\varepsilon$、六个 $1/2+\varepsilon$，$\varepsilon=0.001$。最优解需要几个箱子？三种在线算法（Next Fit / First Fit / Best Fit）各需要几个？

**答案：最优 6 个；Next Fit、First Fit、Best Fit 都是 10 个。**

按讲义给出的顺序（先 6 个 $1/7+\varepsilon$，再 6 个 $1/3+\varepsilon$，最后 6 个 $1/2+\varepsilon$）手算：

| 算法 | 装箱结果 | 箱数 |
|---|---|---:|
| Next Fit | $B_1$：6 个 $1/7+\varepsilon$；$B_2$–$B_4$：各 2 个 $1/3+\varepsilon$；$B_5$–$B_{10}$：各 1 个 $1/2+\varepsilon$ | 10 |
| First Fit | 同上：$1/2+\varepsilon$ 放不进前面任何一箱的剩余空间，只能每次新开一箱 | 10 |
| Best Fit | 同上：所有已有箱子的剩余空间都小于 $1/2+\varepsilon$ | 10 |
| 最优 | 6 箱，每箱装 $1/2+\varepsilon$、$1/3+\varepsilon$、$1/7+\varepsilon$ 各一个 | 6 |

核算几个关键数：

- $1/7+\varepsilon=0.143857\ldots$，六个装一箱：$6\times0.143857\ldots=0.863142\ldots\le1$，再加一个 $1/3+\varepsilon$ 就超过 1；
- $1/3+\varepsilon=0.334333\ldots$，两个一箱：$2\times0.334333\ldots=0.668666\ldots\le1$，三个就超过 1；
- $1/2+\varepsilon=0.501$，两个就超过 1，所以每个 $1/2+\varepsilon$ 只能单独一箱；
- 最优装箱每箱重量 $0.501+0.334333\ldots+0.143857\ldots=0.979190\ldots\le1$，6 箱正好装下 18 件物品。
- 反过来，全部物品的总重量是 $6\times(0.501+0.334333\ldots+0.143857\ldots)=6\times0.979190\ldots=5.875142\ldots>5$，所以 5 个箱子装不下，至少需要 6 箱；上面的构造说明 6 箱够用，故最优值确实是 6。

因此三种在线算法都是 $10$ 箱，而最优只要 $6$ 箱：$10/6=5/3$，正好达到 [§3.3](#33-在线算法-vs-离线算法) 的在线下界 $5/3$——这个例子就是该下界的典型实例。

> 说明：这里按讲义列出的物品顺序计算；换一个输入顺序，Next Fit 的结果可能不同，但本页要展示的就是"在线算法不知道后面还有大件"造成的浪费。

### 10.2 讨论题 15（Discussion 15）：删除半径为什么取 $2r$？

> 【讲义】*Discussion 15: Take $s$ to be the center, how can we select $r$ so that $s$ can cover all the sites that are covered by $c^*$?*

Greedy-2r 的输入 $r$ 是判定阈值（由二分搜索给出，满足 $r(C^*)\le r$），不是我们要优化的半径；这里要选的是**删除半径（deletion radius）**。答案是 $2r$，理由是一次三角不等式：

设 $s$ 是当前 $S'$ 中任取的站点。因为最优中心集 $C^*$ 覆盖所有站点，存在 $c^*\in C^*$ 使

$$\operatorname{dist}(s,c^*)\le r(C^*)\le r.$$

任取一个被 $c^*$ 覆盖的站点 $s'$，也有 $\operatorname{dist}(s',c^*)\le r(C^*)\le r$。由距离的三角不等式，

$$\operatorname{dist}(s,s')\le \operatorname{dist}(s,c^*)+\operatorname{dist}(c^*,s')\le 2r.$$

所以以 $s$ 为中心、半径 $2r$ 删除时，$c^*$ 负责的**整簇站点会被一次删光**。

取 $r$ 不够：$s$ 与 $c^*$ 本身可以相距 $r$，簇边的站点再离 $c^*$ 有 $r$，合起来就是 $2r$。

这也是 [§5.1](#51-greedy-2r给定-r-的判定版decision-version) 定理的证明骨架：把每个被选中的 $s$ 记到"覆盖它的那个 $c^*$"名下；一旦 $s$ 被选中，$c^*$ 的所有站点都被删除，所以同一个 $c^*$ 不会被记两次。若算法选出超过 $K$ 个中心，$C^*$ 就必须有超过 $K$ 个中心，矛盾——于是任何 $K$ 个中心的覆盖半径都大于 $r$。

> 注意：这里用的是 $2r$，不是 $r$；$2$ 这个常数也正是 [§5.3](#53-为什么不能做得更好) 中"不存在 $(2-\varepsilon)$-近似"的临界点。

### 10.3 讨论题：物品重量都不超过 $N^2$ 时，0-1 背包还是 NP 难吗？

> 题面：*A knapsack with a capacity $M$ is to be packed. Given $N$ items. Each item $i$ has a weight $w_i$ and a profit $p_i$. An optimal packing is a feasible one with maximum profit. This problem is NP-hard. However, if no items have a size larger than $N^2$, is it still NP-hard? Explain your answer.*
>
> 出处：课程讨论题。`ADS11Approximation_Stu.ppt` 的幻灯片正文没有收录这一页，故不标页码；下面的解法按本讲 [§4.2](#42-0-1-版每个-x_iin01np-难)–[§4.3](#43-精确-dp-解与利润太大时的舍入rounding) 的 0-1 背包口径整理。

**结论：不再是 NP 难（除非 P = NP）。** 重量上界把 0-1 背包从"弱 NP 难（weakly NP-hard）"变成了多项式时间可解。

#### 10.3.1 按容量做 DP

设 $f[i][j]$ 表示"只考虑前 $i$ 件物品、容量为 $j$"时的最大利润，$i=0,1,\dots,N$，$j=0,1,\dots,M$。边界与转移为

$$f[0][j]=0,\qquad
f[i][j]=
\begin{cases}
f[i-1][j], & j<w_i,\\[2pt]
\max\{f[i-1][j],\ f[i-1][j-w_i]+p_i\}, & j\ge w_i.
\end{cases} \tag{3}$$

答案是 $f[N][M]$。状态数 $O(NM)$，每个状态 $O(1)$ 转移，时间 $O(NM)$；空间可用滚动数组（rolling array）压到 $O(M)$。

#### 10.3.2 一般情况下为什么只是"伪多项式（pseudo-polynomial）"

$M$ 在输入里是以**数值**给出的：它只占 $O(\log M)$ 个二进制位，而 $O(NM)$ 正比于 $M$ 的**数值大小**。例如 $M=2^N$ 时，$O(NM)$ 相对于输入长度是指数级的——这就是"伪多项式"的含义，也是 0-1 背包为**弱 NP 难**的原因。

#### 10.3.3 本题的界把伪多项式变成真多项式

题设每件物品的重量 $w_i\le N^2$，所以所有物品的总重量

$$\sum_{i=1}^{N} w_i\le N\cdot N^2=N^3.$$

容量超过总重量时，直接把所有物品都装进去即可（通常默认 $p_i>0$；若有负利润，先丢掉负利润物品），所以只需考虑

$$M'=\min\left\{M,\ \sum_{i=1}^{N} w_i\right\}\le N^3.$$

把 DP 的容量维从 $M$ 换成 $M'$，答案不变，时间复杂度为

$$O(NM')\le O(N\cdot N^3)=O(N^4),$$

这是 $N$ 的多项式；而输入至少有 $N$ 件物品，$N$ 本身是输入规模的一部分，所以 $O(N^4)$ 也是输入规模的多项式。于是该特例属于 P，**不再是 NP 难**（否则 P = NP）。

#### 10.3.4 和 §4.3 的利润 DP 对照

[§4.3](#43-精确-dp-解与利润太大时的舍入rounding) 的 $W_{i,p}$ 是**按利润做下标**，复杂度 $O(N^2p_{\max})$；本节是按**容量做下标**，复杂度 $O(NM)$。两者都是伪多项式，只是"指数藏在哪个数值参数里"不同：

- 利润 $p_{\max}$ 被多项式界住 → 用利润 DP，多项式；
- 重量（从而容量）被多项式界住 → 用容量 DP，多项式；
- 两边都不加限制 → 0-1 背包弱 NP 难，不能指望这两个 DP 在多项式时间内跑完。

#### 10.3.5 易错点

- **"$O(NM)$ 是伪多项式"不等于"这题还是 NP 难"**：伪多项式只说明 $M$ 很大时会退化；本题 $M$ 的有效上界是 $N^3$，退化条件不成立。
- **容量 $M$ 可以任意大，但不影响结论**：$M>\sum w_i$ 时全装即可，DP 只需做到 $\sum w_i$。
- **重量必须是整数（或可缩放到整数）**：按容量 DP 依赖这个课程默认口径；若重量是任意实数，这套 DP 不适用。
- **$N^2$ 换成 $N^3$ 结论不变**：总重量上界变成 $N^4$，DP 变成 $O(N^5)$，仍是多项式；历年题里出现过 $n^3$ 的版本，答案同样是"不再是 NP 难"。
