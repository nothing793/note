## 2. 基本定义

- **近似比**【讲义定义】：算法产出的解代价 $C$ 与最优解（optimal solution）代价 $C^*$ 满足

$$C\le\rho(n)\,C^*\quad(\text{对任意规模为 } n \text{ 的输入}) \tag{1}$$

  这样的算法叫 $\rho(n)$-近似算法。（一般写作 $\max(C/C^*,C^*/C)$，以适应最大/最小两类问题。）
- **近似方案（approximation scheme）**：不仅接受问题实例（instance），还接受精度参数（accuracy parameter） $\varepsilon>0$；对任意固定的 $\varepsilon$，它是 $(1+\varepsilon)$-近似算法。
- **PTAS**（多项式时间近似方案）：对任意固定的 $\varepsilon>0$，运行时间是输入规模（input size） $n$ 的多项式。
- **FPTAS**（完全多项式时间近似方案）：讲义讲稿备注——"fully"指对 $\dfrac1\varepsilon$ 与 $n$ **都是多项式级**的。

## 3. 装箱问题（Bin Packing）

**问题**：$N$ 个物品（item），尺寸 $0<S_i\le1$，装进容量（capacity）为 1 的箱子，**用最少的箱子**。该问题是 **NP 难**的。

【讲义】的 7 件物品例子：$S_i=0.2,0.5,0.4,0.7,0.1,0.3,0.8$，最优装箱用 **3** 个箱子（$(0.8,0.2)$、$(0.7,0.3)$、$(0.1,0.5,0.4)$）。

### 3.1 Next Fit

```text
读入 item1；此后每读入 item2：能放进当前箱子就放，否则新开一个箱子。
```

> **【定理】** 设最优需要 $M$ 个箱子，则 Next Fit 从不超过 $2M-1$ 个；且存在序列使它真的用到 $2M-1$ 个。

**证明思路**【讲义】：若 Next Fit 用了 $2M$（或 $2M+1$）个箱子，则相邻两箱的尺寸和满足
$$S(B_1)+S(B_2)>1,\quad S(B_3)+S(B_4)>1,\ \dots,\quad S(B_{2M-1})+S(B_{2M})>1$$
于是所有物品的总尺寸 $>M$，而最优解至少要"总尺寸/1"个箱子——即至少 $M+1$ 个，矛盾。

### 3.2 First Fit、Best Fit 及家族

- **First Fit**：扫描**第一个装得下**的箱子，否则开新箱；可用 $O(N\log N)$ 实现。
  > **【定理】** First Fit 从不超过 $17M/10$ 个箱子；存在用到 $17(M-1)/10$ 的序列。
- **Best Fit**：放进**最"紧"**（剩余空间最小）的能容纳它的箱子；$T=O(N\log N)$、箱子数 $\le1.7M$。
- 讲稿备注提到同族还有 **Worst Fit**（装进最不满的箱子）、**Almost Worst Fit**、**Any Fit**，都是 $1.7$ 倍级别的界。
- 【讲义】用同一个 7 物品例子对比三种算法的装箱结果。
- **另一个"很难"的例子**：\#$\left(\tfrac17+\varepsilon\right)$ 类物品 6 个、$\left(\tfrac13+\varepsilon\right)$ 类 6 个、$\left(\tfrac12+\varepsilon\right)$ 类 6 个（$\varepsilon=0.001$）——**最优只需要 6 个箱子，而三种在线算法（online algorithm）都要 10 个**。

### 3.3 在线算法 vs 离线算法

- **在线（on-line）**：处理完一个物品、给出决定后**不能反悔**；你永远不知道输入何时结束。
  > **【定理】** 存在输入，使**任何**在线装箱算法至少用到最优箱数的 $5/3$ 倍。
- **离线（off-line）**：可以先看完所有物品再决定。
  - 思路：**先把物品按尺寸非增（non-increasing）排序（sorting）**，再用 First/Best Fit ⇒ **First Fit Decreasing / Best Fit Decreasing**；
  > **【定理】** FFD 从不超过 $11M/9+6/9$ 个箱子；存在用到 $11M/9+6/9$ 的序列。

## 4. 背包问题（Knapsack）

### 4.1 分数版（fractional）

- 容量 $M$，物品有重量（weight） $w_i$、利润（profit） $p_i$，取 $x_i\in[0,1]$ 的比例，最大化 $\sum p_ix_i$，约束（constraint） $\sum w_ix_i\le M$。
- 三个候选贪心准则（greedy criterion）：最大利润 / 最小重量 / **最大利润密度（profit density） $p_i/w_i$** ← 正确选择。
- 【讲义】例子：$n=3$，$M=20$，$(p_1,p_2,p_3)=(25,24,15)$，$(w_1,w_2,w_3)=(18,15,10)$ ⇒ 解 $(0,1,1/2)$，$P=31.5$。

### 4.2 0-1 版（每个 $x_i\in\{0,1\}$）——**NP 难**

- 【讲义】例子：$n=5$，$M=11$，$p=(1,6,18,22,28)$，$w=(1,2,5,6,7)$
  - 最优解 $(0,0,1,1,0)$：$18+22=40$（重量 $5+6=11$）；
  - 按利润密度贪心得 $(1,1,0,0,1)$：$1+6+28=35$。
- **近似比 = 2** 的证明（$p_{\max}$ 为最大利润）：

$$p_{\max}\le P_{\text{opt}}\le P_{\text{frac}},\qquad p_{\max}\le P_{\text{greedy}}\ \Longrightarrow\ P_{\text{opt}}\le P_{\text{greedy}}+p_{\max}\le2P_{\text{greedy}}$$

（第一式因为最优解一定装得下"利润最大的那件物品"。）

### 4.3 精确 DP 解与"利润太大"时的舍入（rounding）

- 定义 $W_{i,p}$ = 从 $\{1,\dots,i\}$ 中取总利润**恰好为 $p$** 的子集所需的最小重量，三种转移：取 $i$（$W_{i-1,p-p_i}+w_i$）、不取 $i$（$W_{i-1,p}$）、不可能（$\infty$）。规模 $i=1..n$、$p=1..n\,p_{\max}$，故 $O(n^2p_{\max})$。
- $p_{\max}$ 很大时【讲义】：**把利润向上舍入到较小范围**，得到 $(1+\varepsilon)$ 近似；$\varepsilon$ 是精度参数。
- 讲稿备注：**输入规模包含 $p_{\max}$ 的二进制（binary）编码（encoding）长度 $d$**，所以 $p_{\max}=O(2^d)$ 是指数级复杂度——这正是需要舍入的原因。

## 5. K-中心问题（K-center）

- 输入：$n$ 个站点（site） $s_1,\dots,s_n$；选出 $K$ 个中心 $C$，使**每个站点到最近中心的距离的最大值**最小：
  $$\text{dist}(s_i,C)=\min_{c\in C}\text{dist}(s_i,c),\qquad r(C)=\max_i \text{dist}(s_i,C) \tag{2}$$
- **距离的度量（metric）要求**【讲义】：$\text{dist}(x,x)=0$（同一性）、$\text{dist}(x,y)=\text{dist}(y,x)$（对称性）、三角不等式（triangle inequality）。
- 候选中心**无限多**（平面上任意点都可以）。
- **第一次贪心（失败）**：先把第一个中心放在"单个中心的最优位置"，再逐步加中心以尽量减小覆盖半径（covering radius） ⇒ **可以任意差**（*arbitrarily bad*）。

### 5.1 Greedy-2r：给定 $r$ 的判定版（decision version）

```text
Centers Greedy-2r ( Sites S[ ], int n, int K, double r )
{   S' = S; C = ∅;
    while ( S' != ∅ ) {
        Select any s from S' and add it to C;
        Delete all s' from S' with dist(s', s) ≤ 2r;
    }
    if ( |C| ≤ K ) return C;
    else ERROR(No set of K centers with covering radius at most r);
}
```

> **【定理】** 若算法选出的中心多于 $K$ 个，则对任意大小不超过 $K$ 的集合 $C^*$，都有 $r(C^*)>r$。

- 由此可**二分搜索** $r$：每次用 $2r$ 判定，得到 $r_0<r\le r_{\max}$，最终解的半径为 $2r_1$ ⇒ **2-近似**。
- 讲稿备注：若 $r$ 是**整数**，二分只有 $O(\log r)$ 步，是多项式时间。

### 5.2 Greedy-Kcenter：不需要预先知道 $r$

```text
Centers Greedy-Kcenter ( Sites S[ ], int n, int K )
{   C = ∅; Select any s from S and add it to C;
    while ( |C| < K ) { Select s from S with maximum dist(s, C); Add s to C; }
    return C;
}
```

> **【定理】** 该算法返回的 $K$ 个中心满足 $r(C)\le 2\,r(C^*)$——**2-近似**。

### 5.3 为什么不能做得更好

> **【定理】** 除非 P = NP，中心选择问题**不存在** $\rho<2$ 的 $\rho$-近似算法。

证明思路（【讲义】）：若有多项式时间的 $(2-\varepsilon)$-近似，就能多项式时间求解 **DOMINATING-SET**（NP 完全）；支配集问题有大小 $K$ 的解 ⇔ 存在 $K$ 个中心使 $r(C^*)=1$，而所有距离都是整数，$(2-\varepsilon)$-近似只能给出最优解。

## 6. 三个视角（【讲义】收尾页）

| 组合 | 含义 |
|---|---|
| **A+C** | 对**所有**实例都**最优** ⇒ 精确算法（NP 难问题里通常做不到多项式） |
| **A+B** | 精确且高效 ⇒ 只对**特殊实例类**可行 |
| **B+C** | 高效且对所有实例有质量保证 ⇒ **近似算法** |

【讲义】结论：即使 P = NP，也无法同时保证 A+B+C。

## 7. 听课重点与易混点

1. **近似比是"最坏情况（worst case）下的保证"**，与启发式的"平均表现好"不同（讲稿备注）。
2. **在线 vs 离线的分界线是"能否反悔"**：这直接决定了 $2$（或 $17/10$）与 $11/9$ 的界。
3. **装箱的界要记清对应算法**：NF $2M-1$、FF/BF $17M/10$、FFD $11M/9+6/9$、在线下界（lower bound） $5/3$。
4. **0-1 背包的贪心近似比是 2**，证明的关键是 $p_{\max}\le P_{\text{opt}}$ 与 $p_{\max}\le P_{\text{greedy}}$。
5. **$K$-中心的两个算法都是 2-近似**，但一个需要 $r$ 已知（用二分），一个用"最远点优先"。
6. **$\rho<2$ 的不可能性**来自支配集归约（reduction）——这是"近似比有下界"的标准范例。
