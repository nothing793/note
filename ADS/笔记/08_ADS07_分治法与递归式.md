## 1. 一页速览

| 问题 | 本讲要记住的答案 |
|---|---|
| 分治三步 | **划分（divide）** → **递归求解（conquer）** → **合并（combine）** |
| 通用递归式 | $T(n)=a\,T(n/b)+f(n)$（等比例划分）；不平衡划分写成 $T(n)=T(n_1)+T(n_2)+f(n)$ |

| 一句话 | 分治的骨架很容易写，真正决定复杂度的是**合并能否在线性时间内完成**；递归式则要“先看出量级，再严格验证” |

## 2. 分治法：模板、正确性与代价

### 2.1 三步与通用伪代码

【讲义】分治法（divide and conquer）固定三步：

1. **划分（divide）**：把规模 $n$ 的问题分成 $a$ 个子问题（subproblem），通常每个约 $n/b$；
2. **递归求解（conquer）**：递归求解子问题，规模足够小时直接调用基例（base case）；
3. **合并（combine）**：把子问题的解拼成原问题的解。

```text
Solve(P):
    if |P| <= n0: return BaseSolve(P)
    split P into P1, ..., Pa
    return Combine(Solve(P1), ..., Solve(Pa))
```

若划分等比例、合并代价为 $f(n)$，得到

$$T(n)=a\,T(n/b)+f(n),\qquad a\ge1,\ b>1. \tag{1}$$

取整只影响常数；递归式也不一定等比例。快速排序（quicksort）和最近点对内部都可能出现不平衡划分，这时写 $T(n)=\sum_i T(n_i)+f(n)$，不要硬套主方法。

### 2.2 分治正确性要检查什么

只需三件事：基例正确；划分不漏不重（跨界情形由 `Combine` 单独处理）；`Combine` 在子解正确时能推出原解正确。最近点对的难点全部落在最后一条：证明跨界最近点对一定在条带（strip）内，且只需检查常数个候选。

### 2.3 什么时候适合分治

- 子问题**相互独立**；若大量重叠，应转动态规划（dynamic programming）或记忆化（memoization）。
- **合并足够便宜**；合并要 $O(n^2)$ 时，划分再漂亮也未必改善总复杂度。
- **划分尽量平衡**，且递归深度可接受；最坏情况下的快速排序就是反例。

### 2.4 讲义里作为“老朋友”出现的例子

| 问题 | 划分 / 合并 | 递归式 | 结果 |
|---|---|---|---|
| 最大子列和（maximum subarray sum） | 左半、右半、跨中点；跨中点线性扫描 | $T(n)=2T(n/2)+\Theta(n)$ | $\Theta(n\log n)$ |
| 树的遍历（traversal） | 递归左右子树，访问根 | $T(n)=T(L)+T(R)+\Theta(1)$ | $\Theta(n)$ |
| 归并排序（merge sort） | 均分后线性归并 | $T(n)=2T(n/2)+\Theta(n)$ | $\Theta(n\log n)$ |
| 快速排序（quicksort） | 按枢轴（pivot）分成两段 | $T(n)=T(k)+T(n-k-1)+\Theta(n)$ | 平均 $\Theta(n\log n)$，最坏 $\Theta(n^2)$ |

## 3. 最近点对（closest pair problem）

### 3.1 问题与穷举

给定平面上 $n$ 个点，求距离最近的一对点。穷举（brute force）检查 $\binom n2$ 对，代价 $O(n^2)$。分治的目标是把合并压到线性，使总代价降到 $O(n\log n)$。

### 3.2 完整算法：预排序（presorting）与递归

先在每层维护按 $y$ 排好序的点表，避免反复排序。

```text
ClosestPair(Px, Py):
    if |Px| <= 3: return (BruteForce(Px), SortByY(Px))
    mid = floor(|Px| / 2); x_mid = Px[mid].x
    Lx, Rx = split Px at mid
    Ly = [p in Py if p belongs to Lx]
    Ry = [p in Py if p belongs to Rx]
    (delta_L, Ly) = ClosestPair(Lx, Ly)
    (delta_R, Ry) = ClosestPair(Rx, Ry)
    delta = min(delta_L, delta_R)
    Py = MergeByY(Ly, Ry)
    strip = [p in Py if |p.x - x_mid| < delta]
    scan strip; for each point compare at most the next 7 points
    return (delta, Py)
```

关键点：`Ly`、`Ry` 由点的归属从 `Py` 中筛出；每层只做一次线性归并；基例取 $n\le3$，省去 $n=1,2$ 的边界讨论。若每层重新 `sort` 一次，递推式会多一个对数因子，见 §3.5。

### 3.3 为什么只看宽 $2\delta$ 的 strip

设左右两半的最近距离为 $\delta_L,\delta_R$，令 $\delta=\min(\delta_L,\delta_R)$。同一半内的最近点对已由递归找到；若最近点对 $(p,q)$ 跨界且距离 $<\delta$，则 $p,q$ 的 $x$ 坐标都必须落在分界线两侧 $\delta$ 内，否则两点的 $x$ 差已经不小于 $\delta$。所以它们都在宽 $2\delta$ 的 strip 内，且 $y$ 差也小于 $\delta$。

![最近点对：左右递归、strip 与跨界最近点对](assets/fig_closest_pair_demo.png)

*图 1　左右两半的最近距离分别为 $\delta_L=1.118$、$\delta_R=1.414$，取 $\delta=1.118$；跨界点对 $(4.5,3)$ 与 $(5.5,3)$ 的距离为 $1.000<\delta$。图中点集与距离由 `assets/make_ads07_figs.py` 计算生成。*

### 3.4 7 点引理：strip 内为什么是线性扫描

**引理（packing lemma）**：设 $\delta=\min(\delta_L,\delta_R)$。对 strip 中任一点 $p$，在 $y$ 坐标不低于 $p$、且与 $p$ 的 $y$ 差小于 $\delta$ 的点中，最多只有 $7$ 个其他点需要检查。

**证明**：取矩形 $R=[x_{\text{mid}}-\delta,x_{\text{mid}}+\delta]\times[p.y,p.y+\delta]$，它宽 $2\delta$、高 $\delta$，包含所有可能的候选点。把 $R$ 切成 $4\times2=8$ 个边长为 $\delta/2$ 的小格：

- 分界线正好是中间两列的分界，每个小格完整落在左半或右半；
- 同一半内任意两点的距离至少为 $\delta$（因为 $\delta_L,\delta_R\ge\delta$），而小格对角线为 $\delta/\sqrt2<\delta$，故每格至多一个点；
- 因此 $R$ 内至多 $8$ 个点，去掉 $p$ 自己，最多再检查 $7$ 个。

于是 strip 按 $y$ 排序后，每个点只向后看常数个候选；一旦 $y$ 差达到 $\delta$ 就停止。扫描总代价 $O(n)$。

![7 点引理：4×2 网格](assets/fig_closest_packing.png)

*图 2　宽 $2\delta$、高 $\delta$ 的矩形分成 8 个边长 $\delta/2$ 的小格；$p$ 自己占一个位置，所以最多再检查 7 个点。*

### 3.5 正确性与复杂度

正确性用归纳：基例由穷举保证；同一半的最近点对由递归保证；跨界情形由 §3.3、§3.4 保证不会漏掉。

复杂度：预排序 $O(n\log n)$；递归式

$$T(n)=2T(n/2)+O(n)$$

由主方法 Case 2 得 $T(n)=O(n\log n)$。递归栈 $O(\log n)$，峰值空间可做到 $O(n)$。

若每层重新排序，递推式变成 $T(n)=2T(n/2)+O(n\log n)$，解为 $O(n\log^2 n)$——这是最近点对最常见的实现陷阱。若允许重合点，最小距离可能为 $0$；一旦得到 $0$ 可直接返回，避免在 $\delta=0$ 时把 strip 筛空。

## 4. 解递归式的三种方法（【讲义】主线）

### 4.0 先看展开：两种手感

拿到一个递归式，先做题型判断：

- 能写成 $T(n)=aT(n/b)+f(n)$，就先比 $n^{\log_b a}$ 与 $f(n)$，优先试主方法（master theorem）；
- 两者只差一个对数因子，或主方法三档都套不上，就画递归树（recursion tree），再用代入法（substitution method）验证；
- 划分不平衡，或出现 $\sqrt n$ 这类非等比例规模，就用递归树、换元（variable substitution）或直接展开。

【讲义】先用展开法演示两个典型：

$$
T(n)=2T(n/2)+cn
\;\Rightarrow\;
T(n)=2^kT(n/2^k)+kcn
=\Theta(n\log n), \tag{2}
$$

$$
T(n)=2T(n/2)+cn^2
\;\Rightarrow\;
T(n)=2^kT(n/2^k)+cn^2\left(1+\frac12+\cdots+\frac1{2^{k-1}}\right)
=O(n^2). \tag{3}
$$

直觉：**把每一层的代价加起来，看哪一层占主导**。第一式的每层代价相同，共有 $\Theta(\log n)$ 层；第二式的每层代价按 $1/2$ 衰减，几何级数（geometric series）由根节点主导。

### 4.1 代入法（substitution method）——先猜，再归纳证明

**步骤**：

1. 猜一个界，例如 $T(n)=O(n\log n)$；
2. 假设对所有 $m<n$ 成立（强归纳假设（strong induction hypothesis））；
3. 代入递归式，验证对 $n$ 也成立；
4. 选足够大的常数，处理基例。

**例子【讲义】**：$T(n)=2T(\lfloor n/2\rfloor)+n$，猜 $T(n)=O(n\log n)$。

假设对所有 $m<n$ 有 $T(m)\le c\,m\log_2 m$。取 $m=\lfloor n/2\rfloor$，则

$$
\begin{aligned}
T(n)
&\le 2c\left\lfloor\frac n2\right\rfloor
      \log_2\left\lfloor\frac n2\right\rfloor+n\\
&\le c\,n(\log_2 n-1)+n\\
&=c\,n\log_2 n+(1-c)n\\
&\le c\,n\log_2 n \qquad (c\ge 1).
\end{aligned}
$$

基例 $T(2),T(3)$ 取足够大的 $c$ 即可；讲义强调**不必纠结 $T(1)$**，因为渐进记号（asymptotic notation）只关心足够大的 $n$。

**猜错会怎样？** 若猜 $T(n)=O(n)$，写成 $T(m)\le cm$，代入得

$$T(n)\le 2c\left\lfloor\frac n2\right\rfloor+n\le (c+1)n,$$

得到的是 $(c+1)n$，不是原来的 $cn$。这里的问题不是“推出 $O(n)$ 所以 $O(n)$ 成立”，而是**归纳假设没有闭合**：常数从 $c$ 变成了 $c+1$，无法证明存在一个固定的 $c$ 让不等式对所有 $n$ 成立。事实上由递归树可知 $T(n)=\Omega(n\log n)$，所以 $O(n)$ 本来就是错的。

> 代入法的价值：它不依赖主定理的“多项式差距”条件，能处理主定理覆盖不到的缺口，例如 $T(n)=2T(n/2)+n\log n$。

### 4.2 递归树法（recursion-tree method）

递归树（recursion tree）把递归展开画成一棵树：每个结点（node）写子问题的规模，根结点（root）旁边写这一层（或这个结点）的代价；把每层代价求和，再把所有层相加。

![三种典型递归式的递归树](assets/fig_recursion_trees.png)

*图 3　(a) 平衡划分，每层代价相同；(b) 合并代价按 $3/16$ 几何衰减，根节点主导；(c) 不平衡划分，每层总规模仍为 $n$，但最短路径与最长路径只差常数倍。图由 `assets/make_ads07_figs.py` 生成。*

#### 4.2.1 几何衰减：$T(n)=3T(n/4)+\Theta(n^2)$

第 $j$ 层有 $3^j$ 个结点，每个子问题规模为 $n/4^j$，该层代价为

$$3^j\left(\frac{n}{4^j}\right)^2
=\left(\frac{3}{16}\right)^j n^2.$$

因此总代价为

$$T(n)=n^2\sum_{j\ge0}\left(\frac{3}{16}\right)^j
<n^2\cdot\frac{1}{1-3/16}
=\frac{16}{11}n^2=O(n^2).$$

叶结点（leaf）总数为 $3^{\log_4 n}=n^{\log_4 3}\approx n^{0.792}$，低于 $n^2$；根结点贡献 $\Theta(n^2)$，所以 $T(n)=\Theta(n^2)$。

#### 4.2.2 不平衡划分：$T(n)=T(n/3)+T(2n/3)+cn$

这棵树**不平衡**：最短路径每次取 $n/3$，深度为 $\log_3 n$；最长路径每次取 $2n/3$，深度为 $\log_{3/2}n$。两者只差常数倍，因为

$$\frac{\log_{3/2}n}{\log_3 n}
=\frac{\log_2 n/\log_2(3/2)}{\log_2 n/\log_2 3}
=\frac{\log_2 3}{\log_2(3/2)}
\approx 2.71.$$

在每一层，左右子问题的规模之和仍为 $n$，所以每层总代价为 $\Theta(n)$，共有 $\Theta(\log n)$ 层：

$$T(n)=\Theta(n\log n).$$

讲义该页的递归树写着“Not complete!”，因为树形不对称，不能像完全二叉树那样直接数层数。可以用代入法验证上界（upper bound）。设 $T(m)\le d\,m\log m$（用自然对数），则

$$
\begin{aligned}
T(n)
&\le d\frac n3\log\frac n3
   +d\frac{2n}{3}\log\frac{2n}{3}+cn\\
&=d\,n\log n-d\,n\left(\log 3-\frac23\log 2\right)+cn.
\end{aligned}
$$

括号中的常数 $\log 3-\frac23\log2\approx0.637>0$，所以只要 $d\ge c/0.637$，就有 $T(n)\le d\,n\log n$。下界同理，取足够小的 $d$ 即可；因此 $T(n)=\Theta(n\log n)$。

### 4.3 主方法（master theorem）

【讲义】按 CLRS 的形式给出。设 $T(n)=aT(n/b)+f(n)$，其中 $a\ge1$、$b>1$，令

$$p=\log_b a.$$

| 情形 | 条件 | 结论 |
|---|---|---|
| Case 1 | $f(n)=O\big(n^{p-\varepsilon}\big)$，对某个常数 $\varepsilon>0$ | $T(n)=\Theta\big(n^{p}\big)$ |
| Case 2 | $f(n)=\Theta\big(n^{p}\big)$ | $T(n)=\Theta\big(n^{p}\log n\big)$ |
| Case 3 | $f(n)=\Omega\big(n^{p+\varepsilon}\big)$，对某个 $\varepsilon>0$，且满足**正则性条件（regularity condition）** $a f(n/b)\le c f(n)$（某个 $c<1$、足够大的 $n$） | $T(n)=\Theta\big(f(n)\big)$ |

> 讲义注释：$f(n)$ 与 $n^{\log_b a}$ 中较大的那个决定 $T(n)$，而且必须“严格大”，即大出某个**多项式**阶。
> $n\log n$ 只比 $n$ 大一个 $\log$ 因子，不属于“多项式级别”，所以 $T(n)=2T(n/2)+n\log n$ **不能**直接用上面的主方法；要用扩展形式或递归树。

**三种情形的直觉**：

- Case 1：叶子层占主导。第 $j$ 层代价至多按 $b^\varepsilon$ 增长，几何级数求和后由叶子 $n^p$ 决定；
- Case 2：每层代价都是 $\Theta(n^p)$，共 $\Theta(\log n)$ 层；
- Case 3：根节点占主导。正则性条件保证每层代价按常数比例衰减，几何级数求和后仍是 $\Theta(f(n))$。

#### 4.3.1 主定理为什么成立（证明思路）

设 $n=b^k$（忽略取整），第 $j$ 层有 $a^j$ 个结点，每个子问题规模为 $n/b^j$。

**Case 1**：若 $f(n)\le c\,n^{p-\varepsilon}$，则第 $j$ 层代价至多

$$a^j f(n/b^j)
\le c\,a^j\left(\frac{n}{b^j}\right)^{p-\varepsilon}
=c\,n^{p-\varepsilon}\left(b^\varepsilon\right)^j.$$

对 $j=0,\dots,k$ 求和，得到 $O(n^{p-\varepsilon}\cdot n^\varepsilon)=O(n^p)$；叶子层有 $a^k=n^p$ 个结点，代价 $\Theta(n^p)$，所以 $T(n)=\Theta(n^p)$。

**Case 2**：若 $f(n)=\Theta(n^p)$，则第 $j$ 层代价为

$$a^j\Theta\left(\left(\frac{n}{b^j}\right)^p\right)
=\Theta\left(n^p\left(\frac{a}{b^p}\right)^j\right)
=\Theta(n^p).$$

共有 $k+1=\Theta(\log n)$ 层，所以 $T(n)=\Theta(n^p\log n)$。这就是讲义 *Discussion 9* 要证的结论。

**Case 3**：根结点贡献 $f(n)$，给出 $\Omega(f(n))$；正则性条件 $a f(n/b)\le c f(n)$ 使第 $j$ 层代价至多 $c^j f(n)$，所以总代价

$$T(n)\le f(n)\sum_{j\ge0}c^j=\frac{f(n)}{1-c}=O(f(n)).$$

两边合起来即 $T(n)=\Theta(f(n))$。

> **Discussion 9 的完整答案**：Case 2 的证明就是上面的“每层代价相同 + 层数 $\Theta(\log n)$”。若 $f(n)=\Theta(n^p)$，第 $j$ 层的 $a^j$ 个结点各付 $\Theta((n/b^j)^p)$，相乘恰好消去 $a^j$，得到每层 $\Theta(n^p)$；再乘层数 $\Theta(\log n)$。

#### 4.3.2 主方法的另一种形式（Weiss）

【讲义】还给出了 Weiss 教材的写法：设 $T(n)=aT(n/b)+f(n)$，比较 $a f(n/b)$ 与 $f(n)$：

| 条件 | 结论 | 直觉 |
|---|---|---|
| $a f(n/b)=\kappa f(n)$，某常数 $\kappa<1$ | $T(n)=\Theta(f(n))$ | 合并代价逐层按 $\kappa$ 衰减，根节点主导 |
| $a f(n/b)=K f(n)$，某常数 $K>1$ | $T(n)=\Theta(n^{\log_b a})$ | 子问题代价逐层放大，叶子层主导 |
| $a f(n/b)=f(n)$ | $T(n)=\Theta(f(n)\log_b n)$ | 每层代价相同，共 $\log_b n$ 层 |

例：

- $T(n)=2T(n/2)+n$：$a f(n/2)=2\cdot(n/2)=n=f(n)$，得 $\Theta(n\log n)$；
- $T(n)=2T(n/2)+n^2$：$a f(n/2)=2\cdot(n/2)^2=n^2/2=\kappa f(n)$（$\kappa=1/2$），得 $\Theta(n^2)$；
- $T(n)=4T(n/2)+n$：$a f(n/2)=4\cdot(n/2)=2n=K f(n)$（$K=2$），得 $\Theta(n^{\log_2 4})=\Theta(n^2)$。

> 这只是一个便于快速判断的**充分条件**版本；遇到 $a f(n/b)$ 与 $f(n)$ 只差对数因子时，仍要回到递归树或扩展定理。

### 4.4 含 $n^k\log^p n$ 的扩展定理

【讲义】给出：若

$$T(n)=aT(n/b)+\Theta\big(n^k\log^p n\big),\qquad a\ge1,\ b>1,\ p\ge0,$$

则

| 条件 | 结论 |
|---|---|
| $a>b^k$ | $T(n)=\Theta\big(n^{\log_b a}\big)$ |
| $a=b^k$ | $T(n)=\Theta\big(n^k\log^{p+1}n\big)$ |
| $a<b^k$ | $T(n)=\Theta\big(n^k\log^p n\big)$ |

这一定理补上了标准主方法处理不了的一些情形。例如：

- 归并排序：$a=b=2,\ k=1,\ p=0$，属于 $a=b^k$，得 $\Theta(n\log n)$；
- 每次分 3 份、线性合并：$a=3,\ b=2,\ k=1,\ p=0$，$a>b^k$，得 $\Theta(n^{\log_2 3})\approx\Theta(n^{1.585})$；
- 合并代价 $n^2$：$a=b=2,\ k=2,\ p=0$，$a<b^k$，得 $\Theta(n^2)$；
- $T(n)=2T(n/2)+n\log n$：$a=b^k=2,\ k=1,\ p=1$，得 $\Theta(n\log^2 n)$；
- $T(n)=4T(n/2)+n\log n$：$a=4>b^k=2$，得 $\Theta(n^2)$；
- $T(n)=4T(n/2)+n^2$：$a=b^k=4$，得 $\Theta(n^2\log n)$；
- $T(n)=4T(n/2)+n^3$：$a<b^k$，得 $\Theta(n^3)$。

### 4.5 常用递归式速查

| 递归式 | 解 | 用哪一招 |
|---|---|---|
| $T(n)=2T(n/2)+n$ | $\Theta(n\log n)$ | 主方法 Case 2 |
| $T(n)=2T(n/2)+n^2$ | $\Theta(n^2)$ | 主方法 Case 3 |
| $T(n)=3T(n/2)+n$ | $\Theta(n^{\log_2 3})$ | 主方法 Case 1 |
| $T(n)=4T(n/2)+n^2$ | $\Theta(n^2\log n)$ | 主方法 Case 2 |
| $T(n)=4T(n/2)+n^3$ | $\Theta(n^3)$ | 主方法 Case 3 |
| $T(n)=3T(n/4)+n^2$ | $\Theta(n^2)$ | 递归树 / 主方法 Case 3 |
| $T(n)=T(n/3)+T(2n/3)+n$ | $\Theta(n\log n)$ | 递归树 + 代入法 |
| $T(n)=2T(n/2)+n\log n$ | $\Theta(n\log^2 n)$ | 扩展定理 / 递归树 |
| $T(n)=2T(n/2)+n/\log n$ | $\Theta(n\log\log n)$ | 递归树（主方法有缺口） |

> 最后一行是“主定理缺口”的经典例子：$f(n)=n/\log n$ 既不是 $O(n^{1-\varepsilon})$，也不是 $\Omega(n^{1+\varepsilon})$，标准主方法三档都不适用。递归树第 $j$ 层代价为 $n/(\log n-j)$，求和得到 $n\sum_{k=1}^{\log n}1/k=\Theta(n\log\log n)$。

### 4.6 变量代换（variable substitution）：课堂讨论的根号递归式

![课堂讨论的递归式](assets/fig_sqrt_recurrence.png)

课堂讨论要求解

$$T(n)=2T(\lfloor\sqrt n\rfloor)+\log n.$$

**第一步：换变量。** 令 $n=2^m$（严格说取 $m=\log_2 n$；取整只影响常数），则

$$\sqrt n=2^{m/2},\qquad \log_2 n=m.$$

定义 $S(m)=T(2^m)$，原式变成

$$S(m)=2S(m/2)+m. \tag{4}$$

这一步消掉了根号：**指数上的 $\sqrt n$ 变成了规模上的 $m/2$**。

**第二步：解 $S(m)$。** 式 (4) 是标准形式，$a=2$、$b=2$、$f(m)=m$，且

$$m^{\log_b a}=m^{\log_2 2}=m.$$

属于主方法 Case 2：

$$S(m)=\Theta(m\log m).$$

**第三步：换回 $n$。** 由 $m=\log_2 n$，

$$T(n)=S(\log_2 n)=\Theta\big(\log n\cdot\log\log n\big).$$

换底只改变常数因子，所以 $\log$ 的底数不影响 $\Theta$ 结果；但表达式中的“$\log\log n$”要求 $n>1$，小规模由基例处理。

> 同类练习：$T(n)=T(\lfloor\sqrt n\rfloor)+1$。令 $n=2^m$，得 $S(m)=S(m/2)+1=\Theta(\log m)$，所以 $T(n)=\Theta(\log\log n)$。

## 5. 听课重点与易混点

1. **分治的难点通常在合并**：最近点对写起来简单，真正的工作是证明“strip 内只需看 7 个点”。
2. **7 点引理依赖两个条件**：分界线在网格中间（每格完整落在某一半）+ 每一半内部的最近距离至少为 $\delta$。缺一不可。
3. **最近点对的 $O(n\log n)$ 依赖预排序 / 归并维护 $y$ 序**：每层重新排序会变成 $O(n\log^2 n)$。
4. **代入法要先猜，再让常数闭合**：猜 $O(n)$ 时得到 $(c+1)n$，说明假设没有闭合，不是“证出了 $O(n)$”。
5. **主方法不能乱用**：$f(n)$ 与 $n^{\log_b a}$ 必须差一个多项式因子；$n\log n$ 与 $n$ 的差距不够，落在主方法的缺口中。
6. **Case 3 要检查正则性条件**：不是只要 $f(n)$ 大就能用，还要 $a f(n/b)\le c f(n)$（$c<1$）。
7. **递归树不是证明本身**：递归树帮你猜出答案；严格结论还要用代入法或主定理验证。
8. **不平衡递归式要看“层代价”和“层数”两个量**：$T(n)=T(n/3)+T(2n/3)+n$ 的每层代价是 $n$，最短/最长路径只差常数倍，所以仍是 $\Theta(n\log n)$。
9. **取整、边界、重合点**：讲义允许忽略取整；但写论文级证明时要补 $\lfloor\cdot\rfloor$、基例与退化情形。
