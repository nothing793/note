## 1. 一页速览

| 问题 | 讲义给的答案 |
|---|---|
| 本讲目标 | 得到**平衡的二叉搜索树（binary search tree）**（Target: Balanced binary search tree） |
| 红黑树的代价 | 高度（height） $\le 2\log(N+1)$，插入、查找（search）都是 $T=O(\log N)$（讲义写 $O(\ln N)$），可迭代（iteration）实现 |
| 红黑树的存在意义 | 旋转（rotation）次数少（讲义用一张 AVL 与红黑树的对比表说明），是很多标准库 `map/set` 的实现基础 |
| B+ 树 | 为**磁盘（disk）/分层存储（hierarchical storage）**设计的多路平衡查找树（multiway balanced search tree）：阶 $M$ 的 B+ 树，数据全部在叶子（leaf）上 |
| B+ 树关键结论 | 查找 $O(\log N)$；插入（insertion）要分裂（split）；讲义指出 **$M$ 取 3 或 4 最好** |

## 2. 红黑树（Red-Black Trees）

### 2.1 五条性质（property）【讲义定义】

1. 每个节点（node）是红色或黑色（讲义图上还标出 `key / parent / color / left / right` 五个域）；
2. 根是黑色；
3. 每个叶子（**NIL**，外部节点）是黑色；
4. 如果一个节点是红色，那么它的两个孩子（child）都是黑色；
5. 对每个节点，从它到其后代（descendant）叶子的**所有简单路径（simple path）含相同数目的黑节点**。

### 2.2 黑高（black height）与高度上界（upper bound）

- **黑高** $bh(x)$：从 $x$（不含 $x$）向下到叶子的任意简单路径上的黑节点数；$bh(\text{Tree})=bh(\text{root})$。
- **引理（lemma）**：有 $N$ 个内部节点（internal node）的红黑树高度不超过 $2\log(N+1)$。
  讲义给出的归纳证明（induction proof）骨架：对任意节点 $x$，$\text{size}(x)\ge 2^{bh(x)}-1$。
  - $h(x)=0$ 时 $x$ 是 NIL，$\text{size}=2^0-1=0$；
  - 归纳步（inductive step）：$h(x)=k+1$ 时，孩子的黑高要么 $=bh(x)$、要么 $=bh(x)-1$，于是
    $\text{size}(x)=1+2\,\text{size}(\text{child})\ge 2^{bh(x)}-1$；
  - 再由 $bh(\text{Tree})\ge h(\text{Tree})/2$ 得结论。
  【讲义】把这段留成 *Discussion 2: Please finish the proof*——**上课前建议自己把归纳步写完整**。

### 2.3 插入

- 思路【讲义】：**按普通 BST 插入并染成红色**，然后自底向上修复，分 Case 1 / 2 / 3（对称情形同理）。
- 代价 $T=O(h)=O(\log N)$，**可以写成迭代**（不需要递归向上回溯）。

### 2.4 删除（deletion）

- 删除节点的三种情形【讲义】：删叶子 → 把父指针（parent pointer）置 NIL；删度为 1 的节点 → 用其唯一孩子替代；删度为 2 的节点 → 用**左子树（left subtree）最大元**或**右子树（right subtree）最小元**替代，再从子树（subtree）中删掉替代者。
- **只有在被删除节点是黑色时才需要调整**（"Adjust only if the node is black"），替代节点**保持颜色**，等价于"给替代节点所在路径（path）补 1 个黑"。
- 之后按 Case 1 / 2 / 3 / 4 修复：Case 2 是把"需要补黑"的问题继续往上推，Case 4 一次旋转 + 重新着色（recoloring）后结束。
  【讲义】给了完整的 4 个 Case 图和一组具体数字（$10,5,15,3,7,6,8,11,17$）对应的 Case 1 / 2.1 / 2.2 / 3 / 4 演示。

### 2.5 与 AVL 的对比

【讲义】用一张表对比 AVL 与红黑树的**旋转次数**（插入 / 删除）与 $O(\log N)$ 的查找代价：红黑树用**放宽高度平衡**换取了**更少的旋转**，因此在插入删除频繁的场景更省。具体数字见讲义该页表格（课件图片，本笔记不转抄数值）。

## 3. B+ 树（B+ Trees）

### 3.1 定义【讲义定义】

阶为 $M$ 的 B+ 树满足：

1. 根要么是叶子，要么有 2 到 $M$ 个孩子；
2. 所有非叶节点（除根）有 $\lceil M/2\rceil$ 到 $M$ 个孩子；
3. 所有叶子深度（depth）相同；
4. （约定）非根叶子也含 $\lceil M/2\rceil$ 到 $M$ 个孩子（原文：*Assume each nonroot leaf also has between $\lceil M/2\rceil$ and $M$ children*）。

结构要点【讲义】：

- **实际数据全部存放在叶子上**；叶子之间用（图上的）`>>>` 指针（pointer）串联，便于范围查询（range query）；
- 每个内部节点含 $M$ 个指向孩子的指针，以及**除第 1 个之外的每个子树中的最小键**（共 $M-1$ 个键值）。

### 3.2 查找与插入（【讲义】以阶 3 的 2-3 树、阶 4 的 2-3-4 树为例）

- 查找：根到叶逐层比较，命中与否都在叶子判定；
- 插入：先找到合适叶子插入；若节点有 $M+1$ 个键就**分裂**成两个节点（讲义代码写作 $\lceil(M+1)/2\rceil$ 与 $\lfloor(M+1)/2\rfloor$ 个键），若分裂的是根就**新建根**，然后检查父节点（parent node），可能继续向上分裂；
- 讲义演示的序列：阶 3 的树上 `Insert 18`、`Insert 1`、`Insert 19`、`Insert 28`、`Insert 70`，可以看到**分裂与向上传播**；
- 删除：*Deletion is similar to insertion except that the root is removed when it loses two children*；【讲义】提示 *First find a sibling with 2 keys and adjust. Keep more nodes full.*（即优先向有富余的兄弟"借"，保持节点较满）。

### 3.3 复杂度与参数选择（【讲义】结论）

$$
\text{Depth}(M,N)=O\big(\log_{\lceil M/2\rceil}N\big),\qquad
T_{\text{Find}}(M,N)=O(\log N) \tag{1}
$$

- 单个节点内部的搜索（或分裂）代价 $T=O(M)$，从而
  $$T(M,N)=O\!\left(\frac{M}{\log M}\log N\right) \tag{2}$$
- 【讲义】结论：**$M$ 的最佳选择是 3 或 4**。

## 5. 听课重点与易混点

1. **性质 3 里的"叶子"是 NIL 外部节点（external node）**，不是"没有孩子的内部节点"——黑高按这个定义算。
2. **红黑树插入染红色**：因为染红只可能违反性质 4（红节点的孩子必须黑），修复目标单一。
3. **删除只在被删节点为黑色时调整**，替代节点保持原色；"补 1 个黑"的记账方式是理解 Case 1–4 的主线。
4. **B+ 树与 B 树的区别**：B+ 树的数据全在叶子、内部节点只做索引、叶子链支持顺序访问（sequential access）。
5. **阶数（order） $M$ 不是越大越好**：节点内搜索 $O(M)$ 与树高 $O(\log_M N)$ 之间有折中，最佳在 $M=3,4$。
