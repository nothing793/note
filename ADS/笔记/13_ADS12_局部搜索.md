## 1. 一页速览

| 概念 | 讲义给的说明 |
|---|---|
| 目标 | **近似求解**问题——只求一个**局部最优（local optimum）**，不追求全局最优（global optimum） |
| 框架 | 定义**邻域** $N(S)$ → 从可行解（feasible solution）出发 → 在邻域里找更好的解 → 直到无法改进 |
| 两个问题 | ① 算法会不会**有限步终止**？② 得到的局部最优**离全局最优有多远**？ |
| 三种方法 | 梯度下降（Gradient Descent）→ Metropolis → 模拟退火（Simulated Annealing） |
| 两个应用 | **Hopfield 神经网络（neural network）**的状态翻转、**最大割（Maximum Cut）** |
| 关键结论 | 状态翻转（state flipping）必然终止（势能 $\Phi=\sum_{\text{good}}|w_e|$，最多 $W=\sum_e|w_e|$ 步）；**单翻转（flip）邻域的最大割局部最优是 2-近似** |

## 2. 局部搜索框架

```text
SolutionType Gradient_descent()
{   Start from a feasible solution S ∈ FS;
    MinCost = cost(S);
    while (1) {
        S' = Search( N(S) );               /* 在邻域 N(S) 里找"最好的"邻居 */
        CurrentCost = cost(S');
        if ( CurrentCost < MinCost ) { MinCost = CurrentCost; S = S'; }
        else break;
    }
    return S;
}
```

【讲义】的三个要素：

- **邻居关系** $S\sim S'$：$S'$ 由 $S$ 做**小改动**得到；
- **邻域** $N(S)=\{S': S\sim S'\}$；
- **局部最优**：邻域内的最好解。

### 2.1 例子：顶点覆盖（Vertex Cover）

- 可行解集（feasible solution set） $FS$ = 所有顶点覆盖（$V$ 本身就是一个）；$\text{cost}(S)=|S|$；
- 邻居：**增删一个顶点（vertex）**（$S$ 的邻居数 $\le|V|$）；
- 搜索：从 $S=V$ 出发，删掉一个顶点、检查是否还是顶点覆盖且代价更小。
- 【讲义】给出 Case 0 / Case 1 / Case 2 三种"梯度下降卡住"的情形，并留 *Discussion 17：Can you give another case in which gradient descent doesn't work?*
  讲稿备注：对某些情形，随机化（Metropolis）能跳出局部最优；但也有情形会在"加一点、减一点"之间**无限震荡**。

### 2.2 Metropolis 算法与模拟退火

- **Metropolis**【讲义】：每次从 $N(S)$ **随机**取一个 $S'$；若更优就接受；否则**以某个概率（probability）**接受（概率随"变差的幅度"递减、随温度 $T$ 递增），否则跳出循环。
  讲稿备注：这里的"上坡"是允许的——$T$ 很高时上坡概率几乎为 1（在底部来回震荡），$T\to0$ 时上坡概率几乎为 0（退化成梯度下降）。
- **模拟退火**：让"材料"从高温**非常缓慢**地降温，使它在一系列中间温度（temperature）上都达到平衡；降温计划记作 $T=\{T_1,T_2,\dots\}$。

## 3. Hopfield 神经网络

- 模型【讲义】：图 $G=(V,E)$，边权（edge weight） $w_e$ 为**可正可负的整数（integer）**；
  - $w_e<0$：两个端点希望**状态相同**；$w_e>0$：希望**状态不同**；$|w_e|$ 表示这个要求的强度；
  - 输出是一个**配置（configuration）** $S$：给每个顶点赋状态 $s_u\in\{\pm1\}$。
- **三个定义**【讲义】：
  1. 在配置 $S$ 中，边 $e=(u,v)$ 是 **good** 若 $w_es_us_v<0$（即"要求被满足"），否则是 **bad**；
  2. 顶点 $u$ 是 **satisfied**，若与它关联的 good 边的权重（weight）之和 ≥ bad 边的权重之和；
  3. 所有顶点都 satisfied 的配置叫 **stable**。
- 由于各边要求可能互相冲突，**可能不存在**满足所有要求的配置，于是退而求其次：找一个"足够好"的配置。

### 3.1 状态翻转算法（State-flipping Algorithm）

```text
ConfigType State_flipping()
{   Start from an arbitrary configuration S;
    while ( ! IsStable(S) ) { u = GetUnsatisfied(S);  su = - su; }
    return S;
}
```

> **Claim 1（终止性）**：状态翻转算法在至多 $W=\sum_e|w_e|$ 次迭代后停在稳定配置。
>
> **证明**：取进度度量 $\Phi(S)=\sum_{e\ \text{is good}}|w_e|$。翻转 $u$ 时，**与 $u$ 关联的 good 边全部变 bad、bad 边全部变 good**，其他边不变；又 $0\le\Phi(S)\le W$，故单调递增有上界，必然终止。

> **Claim 2**：状态翻转算法在"最大化 $\Phi$"的意义下，**任何局部最大点都是稳定配置**。

【讲义】把这件事写成局部搜索问题：目标函数（objective function） $\Phi$，可行解集 = 所有配置，邻居 = 翻转单个状态。并指出一个**开放问题**：能否在关于 $n$ 与 $\log W$ 多项式（而不是关于 $n$ 与 $W$ 多项式）的时间内构造出稳定状态。

## 4. 最大割问题（Maximum Cut）

- 问题：无向图（undirected graph） $G=(V,E)$，边权 $w_e>0$，把顶点分成 $(A,B)$，使**跨越割的边权之和**最大。
- **玩具应用**【讲义】：$n$ 个活动、$m$ 个人，每人想参加两个活动；把活动安排在上午/下午，使人能同时享受两个活动的数量最大。
- 真实应用：电路布局、统计物理。
- 局部搜索对应关系：可行解 = 任意划分（partition）；邻居 = **把一个顶点从一侧移到另一侧**（single-flip 邻域）；【讲义】指出它是 **Hopfield 网络在所有权重都为正时的特例**——同一个状态翻转算法就可以用。

### 4.1 局部最优有多好

> **Claim**：设 $(A,B)$ 是局部最优划分、$(A^*,B^*)$ 是全局最优，则
> $$w(A,B)\ge\tfrac12\,w(A^*,B^*)$$
> （证明：对局部最优，任一顶点 $u$ 的"移过去"都不会变好，把这些不等式对 $u\in A$ 求和即得。）

历史结果（【讲义】列举）：

- **[Sahni-Gonzales 1976]** 存在最大割的 **2-近似**算法；
- **[Goemans-Williamson 1995]** 存在 **1.1382**-近似算法（approximation algorithm）；
- **[Håstad 1997]** 除非 P = NP，不存在 **17/16**（= 1.0625）近似算法。

### 4.2 改进一：别做太小的改进（big-improvement-flip）

- 状态翻转可能**不在多项式时间（polynomial time）内终止**（步数与 $W$ 有关）。做法：只接受**改进幅度足够大**的翻转（阈值是公式，见课件）。
- 【讲义】两条结论：终止时 $(2+\varepsilon)w(A,B)\ge w(A^*,B^*)$（即质量有保证的近似）；算法在 $O\!\left(\frac n\varepsilon\log W\right)$ 次翻转后终止。
- 讲稿备注给出的证明骨架：每次翻转至少带来一定比例的增长，$n/\varepsilon$ 次后总增长至少翻倍，而总量不超过 $W$，翻倍的次数不超过 $\log W$。

### 4.3 改进二：换一个更大的邻域（Kernighan-Lin 1970）

- **k-flip 邻域**代价是 $\Theta(n^k)$，太大；K-L 折中：
  - Step 1：在当前划分下做**最好的 1-flip**，得到 $(A_1,B_1)$ 并**标记**该顶点；
  - Step k：在**未标记**的顶点里做最好的 1-flip，得到 $(A_k,B_k)$，共标记 $k$ 个顶点；
  - Step n：$(A_n,B_n)=(B,A)$（全翻回来）。
  - 邻域取 $\{(A_1,B_1),\dots,(A_{n-1},B_{n-1})\}$，每次搜索代价从 $O(n^2)$ 降到约 $O(n)$ 级别（讲义写作 $O(n-k+1)$）。
- 【讲义】原话：邻域要**足够丰富**以免陷在坏局部最优，又不能**太大**否则搜不起。讲稿备注：**K-L 的理论分析至今仍未解决**。

## 5. 听课重点与易混点

1. **局部搜索是"近似"方法**：只保证局部最优，质量要靠额外论证（如最大割的 2-近似）。
2. **梯度下降只往下走，Metropolis / 模拟退火允许"上坡"**——这是跳出局部最优的关键。
3. **终止性（termination）不是免费的**：状态翻转靠势能（potential） $\Phi\le W$ 保证终止，但步数与 $W$ 有关（可能指数级）；big-improvement-flip 才换来多项式时间。
4. **Hopfield 与最大割是同一套框架**（后者是前者 $w_e>0$ 的特例），不要当成两个独立算法。
5. **"邻域大小"是显式权衡**：single-flip 便宜但可能卡住，k-flip / K-L 质量更好但搜索更贵。
