## 1. 一页速览

| 概念 | 讲义给的说明 |
|---|---|
| 简单 vs 困难 | 最简单的要 $O(N)$（至少要把输入读一遍）；最困难的是**不可判定问题（undecidable problem）** |
| 不可判定（undecidable）的经典 | **停机问题（halting problem）**：不存在能检测所有死循环的编译程序 |
| 计算模型 | **图灵机**（无限纸带 + 有限状态控制器 + 读写头）；**确定性（deterministic） TM** 每步唯一，**非确定 TM** 可从有限选择中挑一步 |
| NP | "**Non**deterministic **P**olynomial time"；等价定义：**解可以在多项式时间（polynomial time）内被验证** |
| NP 完全 | 最"难"的一类：NP 中任何问题都能**多项式归约（polynomial-time reduction）**到它；只要其中一个能多项式求解，整个 NP 都能 |
| 归约（reduction）方向 | $L_1\le_P L_2$ 表示"$L_1$ 不比 $L_2$ 难"（把 $L_1$ 的实例映射成 $L_2$ 的实例） |
| 两个完整例子 | 哈密顿回路（Hamiltonian cycle） ⇒ 旅行商问题（TSP）；团问题（clique problem） ⇒ 顶点覆盖（vertex cover）问题；SAT/Circuit-SAT 是历史上第一个被证明的 NPC 问题（Cook, 1971） |

## 2. 从"好问题"到"难问题"

【讲义】开篇的一组对照：

| 问题 | 难度 |
|---|---|
| 欧拉回路（每条边恰好走一次） | 容易 |
| 哈密顿回路（经过每个顶点恰一次的简单回路） | **没有已知的多项式算法** |
| 单源无权最短路（unweighted single-source shortest path） | 容易 |
| 单源无权**最长**路 | **没有已知的多项式算法** |

### 2.1 不可判定性

- Hilbert 1900 年提出的 23 个问题之一就是**可判定性**：是否存在一种确定的、原则上能判定一切数学命题的方法？
- Gödel 1931：并非所有由公理系统推出的真命题都可证明——"我们不可能知道一切，也不可能证明一切"。
- **停机问题**【讲义】：编译器能否检测出所有死循环？**答案：不能**。证明：假设存在检测程序 `H(P)`，构造

```text
Loop( P ) {
/* 1 */  if ( H(P) )  print (YES);
/* 2 */  else  infinite_loop();
}
```

  考察 `Loop(Loop)`：若它终止则第 2 行成立说明它死循环，若它死循环则第 1 行成立说明它终止——自相矛盾。**结论：无法判定**。

### 2.2 图灵机（Turing Machine）【讲义】

- **组件**：无限的一维纸带（分格）+ 有限状态控制器（指令存储）+ 一个读写头（read/write head）。
- **每步能做三件事**：改变有限控制状态；擦除当前格符号并写入新符号；读写头左移（L）、右移（R）或不动（S）。
- **设计目标**：模拟"一个数学家（时间、精力、纸笔无限且专注）所能做的任何算术式计算"。
- **确定性 TM**：每个时刻执行一条指令，下一步唯一；**非确定性（nondeterministic） TM**：可以从有限个选项中自由选择，只要其中有一条通往解，它就总能选对。

## 3. NP 与 NP 完全

### 3.1 NP 的定义

- 【讲义】**NP 问题 = 解可以在多项式时间内被验证的问题**。
  例：哈密顿回路——"这条简单回路包含所有顶点（vertex）吗？"可以在多项式时间内检查。
- 【讲义】注意：**并非所有可判定问题（decision problem）都在 NP 里**。例如"判断一个图**不含**哈密顿回路"就不属于 NP（这是 co-NP 侧的典型问题）；而不可判定问题永远不可判定，**不因 NP 的讨论而改变**。

### 3.2 多项式归约

【讲义】给出归约的直观形式：给定问题 A 的任意实例（instance） $\alpha$，若存在程序 $R(\alpha)=\beta$（属于问题 B）耗时 $T_R(N)=O(N^{k_1})$，以及程序 $D(\beta)$ 在 $O(N^{k_2})$ 内给出答案，且**$\beta$ 的答案等于 $\alpha$ 的答案**，则

$$\alpha\in A\ \Longrightarrow\ \beta=R(\alpha)\ \Longrightarrow\ D(\beta)=O(N^k)$$

- 形式化定义：$L_1\le_P L_2$ 若存在多项式时间可计算的 $f$，使对所有 $x$ 有 $x\in L_1\iff f(x)\in L_2$；$f$ 叫**归约函数（reduction function）**。
- **方向感**：$L_1\le_P L_2$ 表示 $L_1$ "不比 $L_2$ 难"（把难问题当黑盒来解 $L_1$）。
- **决策问题（decision problem）更容易**【讲义】；最优化问题可以联系到对应决策问题（例：SHORTEST-PATH 对应 PATH：给定 $k$，是否存在长度 $\le k$ 的路径）。
- **NP 完全的定义**：$L$ 是 NP 完全的，若
  1. $L\in\text{NP}$；
  2. 对所有 $L'\in\text{NP}$ 都有 $L'\le_P L$。

### 3.3 形式语言（formal language）框架（【讲义】后半段的"严谨版"）

- **抽象问题（abstract problem）** $Q$：实例集合 $I$ 与解集合 $S$ 上的二元关系；**决策问题**的解集是 $\{0,1\}$。
- **编码（encoding）**：把 $I$ 映射成 $\{0,1\}^*$ 上的串，得到**具体问题（concrete problem）**。
- **语言**：字母表（alphabet） $\Sigma$ 上的语言 $L\subseteq\Sigma^*$；对决策问题取 $L=\{x\in\Sigma^*: Q(x)=1\}$。
- **接受 / 判定**：算法 $A$ 接受 $x$ 若 $A(x)=1$；语言 $L$ 被 $A$ **判定**要求 $L$ 内全接受、$L$ 外全拒绝。
- $$P=\{L\subseteq\{0,1\}^*:\text{存在多项式时间算法判定 }L\}$$
- **验证算法（verification algorithm）**：两参数算法 $A(x,y)$，$y$ 叫**证书（certificate）**；$L$ 属于 NP 当且仅当存在多项式时间的两参数算法 $A$ 与常数 $c$，使
  $$L=\{x:\exists y,\ |y|=O(|x|^c),\ A(x,y)=1\}$$（$y$ 就是"猜出来的解"。）
- **co-NP**：$\overline{L}\in\text{NP}$ 的语言类；讲义画出四种可能的关系（$P=NP=co\text{-}NP$、$NP=co\text{-}NP$、$P=NP\cap co\text{-}NP$ 等）。

### 3.4 第一个 NPC 问题

- **可满足性问题（Satisfiability / Circuit-SAT）**：给定布尔表达式（Boolean expression），问是否存在赋值（assignment）使它为 1。
- **Cook 1971**：NP 中所有问题都能多项式归约到可满足性（通过在非确定 TM 上多项式时间地求解该问题来证明）。

## 4. 两个完整的 NPC 证明（讲义示范）

### 4.1 哈密顿回路 ⇒ TSP

- **TSP（决策版）**：给定带权完全图 $G=(V,E)$ 与整数 $K$，是否存在总代价 $\le K$ 的哈密顿回路？
- **证明**：① TSP $\in$ NP（给定回路多项式验证）；② 归约：把哈密顿回路的图 $G$ 补成完全图 $G'$——原图中的边权（edge weight）取 1，新增的边权取 2，取 $K=|V|$。则
  $$G\ \text{有哈密顿回路}\iff G'\ \text{有总权 }|V|\ \text{的旅行商回路}$$

### 4.2 团问题 ⇒ 顶点覆盖问题

- 记 `CLIQUE={<G,K>: G 中有 K 个顶点的完全子图}`、`VERTEX-COVER={<G,K>: G 有 K 个顶点的顶点覆盖}`。
- ① **VERTEX-COVER $\in$ NP**：证书取 $V'\subseteq V$；验证 $|V'|=K$ 且每条边至少有一个端点在 $V'$ 中，$O(N^3)$。
- ② **CLIQUE $\le_P$ VERTEX-COVER**：$G$ 有大小 $K$ 的团 $\iff$ 其补图（complement graph） $\overline{G}$ 有大小 $|V|-K$ 的顶点覆盖（讲义给出双向推导，$O(N^2)$）。
  - 正向：若 $V'$ 是团，则对 $\overline G$ 的任意边 $(u,v)$，$u,v$ 不可能同在 $V'$，故 $V-V'$ 覆盖 $\overline G$ 的每条边；
  - 反向：若 $V'$ 是 $\overline G$ 的大小 $|V|-K$ 的顶点覆盖，则 $V-V'$ 内任意两点在 $\overline G$ 中无边，即在 $G$ 中有边 ⇒ $V-V'$ 是大小为 $K$ 的团。

## 5. 听课重点与易混点

1. **归约方向**：要证 $X$ 是 NPC，先把**已知的 NPC 问题归约到 $X$**（不是反过来）。$L_1\le_P L_2$ 表示 $L_2$ 至少和 $L_1$ 一样难。
2. **"NP = 多项式时间可验证"** 与 "NP = 非确定图灵机多项式时间可解" 是同一件事的两种说法。
3. **P ⊆ NP 是显然的**（能判定就能验证），反过来是否成立未知。
4. **不是所有可判定问题都在 NP**（"不含哈密顿回路"这类否证型问题）。
5. **证书必须多项式长**：$|y|=O(|x|^c)$ 是定义的一部分，别漏。
