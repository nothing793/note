## 1. 一页速览

| 关键词 | 必须记住的结论 |
|---|---|
| **P** | 确定性图灵机（deterministic Turing machine）能在多项式时间（polynomial time）内**判定**的语言类 |
| **NP** | 解可以在多项式时间内被**验证**；等价地，非确定性图灵机（nondeterministic Turing machine）能在多项式时间内判定 |
| **co-NP** | 补问题（complement problem）属于 NP 的语言类：$L\in\text{co-NP}\iff \overline L\in\text{NP}$ |
| **NP-hard** | 所有 NP 问题都能多项式归约到它；**不要求它自己属于 NP** |
| **NP-complete** | 同时满足：① 属于 NP；② 是 NP-hard。即 $\text{NPC}=\text{NP}\cap\text{NP-hard}$ |
| 已知包含关系 | $P\subseteq NP\subseteq EXP$，且 $P\subseteq NP\cap co\text{-}NP$；$P=NP$、$NP=co\text{-}NP$ 都未知 |
| 归约方向 | $L_1\le_P L_2$ 表示“$L_1$ 不比 $L_2$ 难”；证明 $X$ 是 NPC，要把**已知 NPC 问题归约到 $X$** |
| 第一个 NPC 证明链 | CLRS 以 **Circuit-SAT** 为起点，再证 **SAT**、**3-SAT**；Cook–Levin 定理通常直接表述为 SAT 是 NPC |
| 常见 NPC | SAT、3-SAT、团（clique）、独立集（independent set）、顶点覆盖（vertex cover）、哈密顿回路（Hamiltonian cycle）、TSP 判定版、子集和（subset sum）、集合覆盖（set cover）等 |
| 不可判定 | 停机问题（halting problem）、波斯特对应问题（Post Correspondence Problem, PCP）；它们不属于 NP，更不可能是 NPC |
| 本讲在期末的位置 | 加权占比约 **10.2%**，是期末第一优先；高频是包含关系、归约方向、NPC 证明与“给一个 NP 问题判断哪些命题成立” |

**三条主线：**

1. **难度分层**：可判定问题里，P 是最容易的一层；NP 是“解容易验证”的一层；NPC 是 NP 中最难的一层；NP-hard 可以难到 NP 之外。
2. **比较工具**：多项式归约把“解 A 的方法”变成“解 B 的方法”。归约的方向决定结论的方向。
3. **证明模板**：证明 $X$ 是 NPC，先证 $X\in NP$，再选一个已知 NPC 的 $Y$，构造 $Y\le_P X$，最后证明双向等价并检查多项式时间。

## 2. 从“容易”到“困难”

### 2.1 四组对照

| 容易的问题 | 困难的问题 | 关键区别 |
|---|---|---|
| 欧拉回路（Euler circuit，每条边恰好走一次） | 哈密顿回路（Hamiltonian cycle，每个顶点恰好经过一次） | “边一次”有简单的度数条件；“顶点一次”没有已知多项式算法 |
| 单源最短路（shortest path） | 一般图上的最长简单路径（longest simple path） | 最短路满足最优子结构；最长简单路径要求路径不重复顶点，哈密顿路径是它的特例 |
| DAG 上的最长路 | 一般图上的最长路 | 有向无环图（directed acyclic graph, DAG）没有环，可以按拓扑序（topological order）做 DP；一般图有环，且要排除重复顶点 |
| 2-SAT | 3-SAT | 2-SAT 可用强连通分量（strongly connected component, SCC）在多项式时间求解；3-SAT 是 NPC |

几个要能当场说清的点：

- **欧拉回路**只要求每条边一次，存在性是“连通 + 所有顶点度数为偶数”的多项式判定；**哈密顿回路**要求每个顶点一次，是 NPC。
- **最短路**在非负权下可用 Dijkstra，在无负权回路时可用 Bellman–Ford，全源可用 Floyd–Warshall；**最长简单路径**在一般图上是 NP-hard，因为取所有边权为 1、问是否有长度为 $n-1$ 的简单路径，就得到哈密顿路径问题。
- **DAG 最长路**可以在拓扑序上做
  $$d[v]=\max_{(u,v)\in E}\{d[u]+w(u,v)\},$$
  时间 $O(V+E)$。这说明“问题难”往往难在一般图的结构约束，而不是“最长”两个字本身。
- **2-SAT 与 3-SAT 的分界**说明子句长度也会改变难度：2-SAT 的蕴含图（implication graph）方法给出多项式算法；3-SAT 则是 NP 完全的起点问题之一。

### 2.2 Floyd 取反的陷阱

一个常见的错误是：想求最长简单路径，就把每条边权取反，令

$$w'(u,v)=-w(u,v),$$

再用 Floyd 求最短路。这个做法在一般图上不成立。

- 如果原图有一条**正权回路**（positive-weight cycle），取反后就是**负权回路**（negative-weight cycle）。最短路会沿着负权回路无限绕下去，距离没有有限下界；Floyd-Warshall 也处理不了这种情形（只能报告存在负权回路）。
- 最长路径要求的是**简单路径**（simple path），不允许重复顶点；而“取反后求最短路”求的是**最短 walk**，并没有把“顶点不能重复”作为约束。负权回路正是算法利用重复顶点降低代价的地方。
- 如果原图是 DAG，根本没有回路，取反后不会出现负权回路，拓扑序 DP（或 Bellman–Ford）可以求最长路；但这依赖于“无环”，不是一般图上的解法。
- 一般图上的最长简单路径是 NP-hard；不能指望用一个多项式的最短路算法顺手解决它。

**取反只能把“最长”改成“最短”，不能把“简单路径”这个约束一起变过去。**

### 2.3 多项式时间的意义

- 多项式时间 $O(n^k)$ 与指数时间（exponential time）$2^{n^k}$ 的差距，在输入规模稍大时差距很大。多项式时间算法通常可以随输入规模扩展；指数时间算法很快只能处理很小的实例。
- “多项式”不是“对所有实例都很快”的承诺：$n^{100}$ 仍然可能很慢。复杂度理论关心的是**随输入规模增长的阶**，不是某台机器上的常数。
- 多项式时间对**复合**（composition）封闭：如果一个问题能多项式归约到另一个多项式可解的问题，那么原问题也可多项式求解。归约能用来比较难度，靠的就是这个性质。
- $P\ne NP$ 时，NPC 问题仍然**可判定**：枚举所有长度不超过多项式界的证书（certificate），总能在指数时间内求出答案。**NP 不等于“不可解”，也不等于“指数时间”**。
- 现代公钥密码（public-key cryptography）常用的整数分解（integer factorization）、离散对数（discrete logarithm）等问题都在 NP 中；如果 $P=NP$，这些基于计算难度的假设会失效。但不要把口号写成“所有加密都要重写”：一次一密（one-time pad）仍是信息论安全的，密码学还需要平均情况（average-case）困难性，$P\ne NP$ 本身也不足以保证安全。

### 2.4 不可判定性

- Hilbert 1900 年提出的问题之一就是**可判定性**（decidability）：是否存在一种确定的、原则上能判定一切数学命题的方法？
- Gödel 1931：并非所有由公理系统推出的真命题都可证明——“我们不可能知道一切，也不可能证明一切”。
- **停机问题**（halting problem）【讲义】：编译器能否检测出所有死循环？**答案：不能**。证明：假设存在检测程序 `H(P)`，构造

```text
Loop( P ) {
/* 1 */  if ( H(P) )  print (YES);
/* 2 */  else  infinite_loop();
}
```

考察 `Loop(Loop)`：若它终止，则第 2 行成立说明它死循环；若它死循环，则第 1 行成立说明它终止——自相矛盾。**结论：无法判定**。

- **波斯特对应问题**（Post Correspondence Problem, PCP，也叫“骨牌问题”）：给定有限块骨牌，每块上下各有一个字符串，问能否把骨牌排成一个非空序列，使上排拼接与下排拼接完全相同。PCP 是**不可判定**的；它可以用骨牌序列模拟图灵机的计算过程。
- 不可判定问题不属于 NP：NP 中的问题至少有“猜一个多项式长证书并验证”的判定方法，因此一定是可判定的。**停机问题不是 NPC**；按多项式多一归约的口径，它可以是 NP-hard，但它不在 NP 中，所以不满足 NPC 的第一条。

## 3. 形式化基础：语言与图灵机

### 3.1 判定问题、语言与编码

- **抽象问题**（abstract problem）$Q$：实例集合 $I$ 与解集合 $S$ 上的二元关系；**判定问题**（decision problem）的解集是 $\{0,1\}$。
- **编码**（encoding）：把实例映射成 $\{0,1\}^*$ 上的串，得到**具体问题**（concrete problem）。同一个抽象问题用不同编码，复杂度可能不同；本课默认使用二进制编码（binary encoding）。
- **字母表**（alphabet）$\Sigma$ 上的**语言**（language）是 $L\subseteq\Sigma^*$。对判定问题取
  $$L=\{x\in\Sigma^*:Q(x)=1\}.$$
- **接受 / 判定**：算法 $A$ **接受**（accept）$x$ 若 $A(x)=1$；语言 $L$ 被 $A$ **判定**（decide）要求 $L$ 内全接受、$L$ 外全拒绝。
- **最优化问题转判定问题**：例如 SHORTEST-PATH 的判定版 PATH 问“给定 $k$，是否存在长度 $\le k$ 的路径”；TSP 的判定版问“是否存在总代价 $\le K$ 的旅行商回路”。NPC 的定义通常只直接作用于判定问题；最优化版本常说“NP-hard”。

### 3.2 图灵机

- **组件**：无限的一维纸带（分格）+ 有限状态控制器（指令存储）+ 一个读写头（read/write head）。
- **每步能做三件事**：改变有限控制状态；擦除当前格符号并写入新符号；读写头左移（L）、右移（R）或不动（S）。
- **设计目标**：模拟“一个数学家（时间、精力、纸笔无限且专注）所能做的任何算术式计算”。
- **确定性图灵机**（deterministic TM）：每个时刻执行一条指令，下一步唯一。
- **非确定性图灵机**（nondeterministic TM）：可以从有限个选项中自由选择；只要存在一条接受分支，它就接受。直观上像一台“总能猜对”的机器（lucky machine）。
- NP 的两种等价说法：**非确定图灵机多项式时间可判定**；**确定性图灵机多项式时间可验证**。

### 3.3 P、NP 与 EXP

- **P**：
  $$P=\{L\subseteq\{0,1\}^*:\text{存在多项式时间算法判定 }L\}.$$
- **NP**（*Non*deterministic *P*olynomial time）：存在多项式时间的两参数验证算法 $A(x,y)$ 和常数 $c$，使
  $$L=\{x:\exists y,\ |y|=O(|x|^c),\ A(x,y)=1\}.$$
  这里的 $y$ 叫**证书**（certificate），就是“猜出来的解”。
- **EXP**：存在 $k$，可在 $O(2^{n^k})$ 时间内判定的语言类。
- NP 的验证算法只负责“检查证书”，不负责“找证书”。例如哈密顿回路：给定一条回路，多项式时间就能检查它是否经过每个顶点恰好一次；但找这条回路没有已知多项式算法。

### 3.4 复杂度类关系

| 关系 | 是否已知 | 说明 |
|---|---|---|
| $P\subseteq NP$ | 已知 | 能判定就能验证：忽略证书，直接运行判定算法 |
| $P\subseteq co\text{-}NP$ | 已知 | P 对补运算封闭 |
| $P\subseteq NP\cap co\text{-}NP$ | 已知 | 由上面两条推出 |
| $NP\subseteq EXP$ | 已知 | 枚举所有长度不超过多项式界的证书，指数时间可判定 |
| $P=NP$ | **未知** | 若成立，NPC 问题全部有多项式算法 |
| $NP=co\text{-}NP$ | **未知** | 若 $NP\ne co\text{-}NP$，则必有 $P\ne NP$ |

注意：$P\subseteq NP\subseteq EXP$ 不代表“NP 就是指数时间”；NP 只是“解容易验证”的一层，指数时间只是它的一个上界。

## 4. NP-hard、NP-complete 与 co-NP

### 4.1 NP-hard

语言 $L$ 是 **NP-hard** 的，若对所有 $L'\in NP$ 都有

$$L'\le_P L.$$

NP-hard **不要求** $L\in NP$。因此：

- NP-hard 问题可以比 NP 更难，甚至不可判定；
- “NP-hard 问题都是 NP 问题”是**错**的；
- 停机问题是 NP-hard（按多一归约口径），但它不在 NP 中，所以不是 NPC。

### 4.2 NP-complete

语言 $L$ 是 **NP-complete**（NPC）的，若：

1. $L\in NP$；
2. 对所有 $L'\in NP$ 都有 $L'\le_P L$（即 $L$ 是 NP-hard）。

等价地，$\text{NPC}=\text{NP}\cap\text{NP-hard}$。于是：

- NPC 一定是 NP-hard，但 NP-hard 不一定是 NPC；
- 只要任意一个 NPC 问题属于 P，就有 $P=NP$；
- 只要任意一个 NP-hard 问题属于 P，也有 $P=NP$（因为所有 NP 问题都能归约到它）；
- 若 $P\ne NP$，NPC 问题不在 P 中，但仍然可判定，只是目前只能做到指数级。

### 4.3 co-NP

- **补语言**（complement）：$\overline L=\{x:x\notin L\}$。
- **co-NP**：$L\in co\text{-}NP\iff \overline L\in NP$。
- 典型例子：SAT 的补问题 UNSAT（公式不可满足）、哈密顿回路的补问题 NO-HAMILTON（图不含哈密顿回路）。
- 这些补问题的“是”答案需要证明**所有**赋值/所有回路都不成立，目前没有已知的多项式长证书；所以不能因为它们“看起来难”就说它们不在 NP。它们属于 co-NP，是否也在 NP 中正是 $NP=co\text{-}NP$ 问题。
- **常见错误**：把“判断一个图不含哈密顿回路”当作“已知不属于 NP”的例子。正确的说法是：它属于 co-NP；它是否属于 NP 未知。

### 4.4 co-NP 证明练习

#### 4.4.1 P=NP 推出 NP=co-NP

证明：

1. P 对补运算封闭：若 $L\in P$，则 $\overline L\in P$，即 $P=coP$。
2. 假设 $P=NP$，则
   $$co\text{-}NP=coP=P=NP.$$
3. 因此 $NP=co\text{-}NP$。

#### 4.4.2 NPC 在 co-NP 中推出 NP=co-NP

这里 NPC 采用标准的多项式时间多一归约定义。

先证 $NP\subseteq co\text{-}NP$。取任意 $L\in NP$。因为 $A$ 是 NPC，存在多项式时间可计算的函数 $f$，使

$$x\in L\iff f(x)\in A. \tag{1}$$

两边同时取否定：

$$x\notin L\iff f(x)\notin A,$$

也就是

$$x\in\overline L\iff f(x)\in\overline A. \tag{2}$$

所以同一个 $f$ 同时给出

$$L\le_P A,\qquad \overline L\le_P\overline A.$$

又因为 $A\in co\text{-}NP$，所以 $\overline A\in NP$。NP 对多项式归约封闭，因此由 $\overline L\le_P\overline A$ 得 $\overline L\in NP$，即 $L\in co\text{-}NP$。于是

$$NP\subseteq co\text{-}NP. \tag{3}$$

再证反方向。取任意 $K\in co\text{-}NP$，则 $\overline K\in NP$。由 (3) 得 $\overline K\in co\text{-}NP$，再用 co-NP 的定义：

$$\overline{\overline K}=K\in NP.$$

所以 $co\text{-}NP\subseteq NP$。结合 (3) 得 $NP=co\text{-}NP$。

#### 4.4.3 常用结论

| 命题 | 结论 | 理由 |
|---|---|---|
| $P\subseteq NP\cap co\text{-}NP$ | 成立 | P 对补封闭，且 $P\subseteq NP$ |
| $P=NP\Rightarrow NP=co\text{-}NP$ | 成立 | 上面的 4.4.1 |
| $A$ 是 NPC 且 $A\in co\text{-}NP\Rightarrow NP=co\text{-}NP$ | 成立 | 上面的 4.4.2 |
| $NP\ne co\text{-}NP\Rightarrow P\ne NP$ | 成立 | 逆否命题：$P=NP\Rightarrow NP=co\text{-}NP$ |
| $NP=co\text{-}NP\Rightarrow P=NP$ | 不能推出 | 这是另一个未解决问题，不要拿来当定理 |

## 5. 多项式归约

### 5.1 定义与方向

**多项式归约**（polynomial-time reduction）：$L_1\le_P L_2$，若存在多项式时间可计算的函数 $f$，使对所有 $x$ 有

$$x\in L_1\iff f(x)\in L_2.$$

$f$ 叫**归约函数**（reduction function）。直观上：

- 想解 $L_1$，先算 $f(x)$，再把 $f(x)$ 交给解 $L_2$ 的算法；
- 所以 $L_1$ **不比** $L_2$ 难；
- 反过来，$L_2$ 至少和 $L_1$ 一样难。

归约必须满足：

1. $f$ 在多项式时间内可计算；
2. $f(x)$ 的长度是多项式；
3. 双向等价成立（不能只证一个方向）；
4. 归约的复杂度按输入规模 $|x|$ 计算。

### 5.2 NPC 证明模板

要证明问题 $X$ 是 NPC：

1. **先证 $X\in NP$**：给出证书的形式（例如顶点集合、赋值、排列），再写多项式验证算法。
2. **选一个已知 NPC 的 $Y$**（SAT、3-SAT、团、顶点覆盖、哈密顿回路等）。
3. **构造 $Y\le_P X$**：把 $Y$ 的任意实例 $y$ 多项式时间映射成 $X$ 的实例 $f(y)$。
4. **证明双向等价**：
   - $y$ 是 $Y$ 的“是”实例 $\Rightarrow f(y)$ 是 $X$ 的“是”实例；
   - $f(y)$ 是 $X$ 的“是”实例 $\Rightarrow y$ 是 $Y$ 的“是”实例。
5. **检查规模与时间**：$|f(y)|$ 必须是 $|y|$ 的多项式，构造也必须多项式时间。

只证“$X$ 能归约到某个 NPC 问题”是不够的：那只说明 $X$ 不比 NPC 难，不能说明 $X$ 是 NPC。方向必须是**已知 NPC $\le_P X$**。

### 5.3 归约方向速查

| 已知 | 可以推出 | 不能推出 |
|---|---|---|
| $A$ 是 NPC，$B\in NP$，$A\le_P B$ | $B$ 是 NPC | — |
| $A$ 是 NPC，$B\le_P A$ | $B$ 不比 $A$ 难；若 $B\in NP$，$B$ 可能只是 P | $B$ 是 NPC |
| $A$ 是 NP-hard，$A\le_P B$ | $B$ 是 NP-hard | 若不再证 $B\in NP$，不能推出 $B$ 是 NPC |
| $A\in P$ 且 $A$ 是 NP-hard | $P=NP$ | — |
| $A$ 是 NPC 且 $A\in P$ | $P=NP$ | — |
| $Q\in NP$，SAT 有多项式算法 | $Q$ 有多项式算法（因为 $Q\le_P SAT$） | — |
| $Q\in NP$，$Q$ 有多项式算法 | 只说明 $Q$ 容易 | SAT 有多项式算法或 $P=NP$ |

### 5.4 常见错误

1. **归约方向写反**：要证 $X$ 难，必须把已知 NPC 问题归约到 $X$，不是把 $X$ 归约到已知 NPC。
2. **忘了证 $X\in NP$**：只做了归约，只能得到 NP-hard，不能得到 NPC。
3. **证书长度不是多项式**：NP 定义要求 $|y|=O(|x|^c)$，不能给一个指数长的证书。
4. **只证一个方向**：归约要求“是实例 iff 是实例”，两个方向都要写。
5. **构造不是多项式时间**：例如枚举所有子集再选一个，不能算多项式归约。
6. **把最优化版和判定版混在一起**：NPC 定义通常先对判定问题说；最优化版说 NP-hard 更自然。
7. **把 co-NP 当成 NP 的补集本身**：co-NP 是“补语言属于 NP”的语言类，不是“NP 的补集”这种简单集合差。

## 6. 经典 NPC 问题与证明

### 6.1 第一个 NPC 问题：Circuit-SAT、SAT 与 3-SAT

- **电路可满足性问题**（Circuit Satisfiability, CIRCUIT-SAT）：给定一个布尔电路（Boolean circuit），问是否存在输入赋值使输出为 1。
- **可满足性问题**（Satisfiability, SAT）：给定一个布尔公式（Boolean formula），问是否存在赋值使它为 1。
- **3-SAT**：给定合取范式（conjunctive normal form, CNF），每个子句（clause）恰有 3 个文字（literal），问是否存在满足赋值。
- **Cook–Levin 定理**：SAT 是 NP 完全的；证明思路是把任意 NP 计算（非确定图灵机的计算过程）编码成一个布尔公式，使“公式可满足”等价于“机器接受”。
- **口径说明**：CLRS 的证明链先把 **CIRCUIT-SAT** 证成 NPC，再归约到 SAT、3-SAT；Cook–Levin 定理通常直接表述为 SAT 是 NPC。两者指的是同一条证明链的不同起点；考试问“第一个”时，按课堂/教材的措辞答，别把 SAT 与 CIRCUIT-SAT 当成同一个对象。
- 3-SAT 是后续归约最常用的起点：它比一般 SAT 结构更整齐，适合构造“子句 gadget”。

### 6.2 从哈密顿回路到 TSP

- **哈密顿回路问题**（Hamiltonian cycle problem, HCP）：给定无向图 $G=(V,E)$，问是否存在经过每个顶点恰好一次的简单回路。
- **TSP 判定版**：给定带权完全图 $G'=(V,E')$ 与整数 $K$，问是否存在总代价 $\le K$ 的哈密顿回路（旅行商回路）。
- **第一步：TSP $\in$ NP**。证书取一个顶点排列；验证它确实是所有顶点的一个排列、相邻顶点在 $G'$ 中都有边、总权 $\le K$，多项式时间。
- **第二步：HCP $\le_P$ TSP**。把 $G$ 补成完全图 $G'$：
  - 原图中的边权取 1；
  - 新增的边权取 2；
  - 取 $K=|V|$。
- **正确性**：
  - 若 $G$ 有哈密顿回路，则这条回路在 $G'$ 中只用权 1 的边，总权 $|V|$，所以 TSP 有解。
  - 若 $G'$ 有总权 $\le |V|$ 的旅行商回路，回路共有 $|V|$ 条边，每条边权至少为 1，因此总权至少为 $|V|$；要不超过 $|V|$，每条边都必须权 1，也就是全部来自原图 $G$。所以这条回路就是 $G$ 的哈密顿回路。
- 构造只需要把非边补成权 2 的边，$O(|V|^2)$ 时间，所以是多项式归约。因此 TSP 判定版是 NPC。

### 6.3 从 3-SAT 到独立集

- **独立集问题**（independent set, IS）：给定图 $G=(V,E)$ 与整数 $K$，问是否存在大小 $K$ 的顶点子集 $S$，使 $S$ 中任意两点之间都没有边。
- **第一步：IS $\in$ NP**。证书取顶点集合 $S$；验证 $|S|=K$，并检查 $S$ 内任意两点之间没有边，$O(K^2)$ 时间。
- **第二步：3-SAT $\le_P$ IS**。设 3-SAT 公式有 $k$ 个子句，每个子句恰有 3 个文字（重复出现的文字按不同顶点处理）。构造图 $G_\varphi$：
  1. 对每个子句 $C_i=(l_{i1}\lor l_{i2}\lor l_{i3})$，建三个顶点，分别标记为 $l_{i1},l_{i2},l_{i3}$；
  2. 在同一个子句的三个顶点之间两两连边，形成一个三角形（triangle）；
  3. 对不同子句中**互补**的文字（$x$ 与 $\neg x$）连边；相同文字不连边。
- **为什么是独立集**：
  - 每个子句内部是三角形，独立集最多只能从每个子句选一个顶点；
  - 若选了两个互补文字，它们之间有边，违反独立集定义；
  - 所以大小 $k$ 的独立集必须“每个子句恰好选一个文字”，且选出的文字之间没有矛盾。
- **正确性**：
  - 若公式可满足，每个子句至少有一个真文字；从每个子句选一个真文字对应的顶点。不同子句选出的真文字不可能互补（互补文字不可能同时为真），所以得到大小 $k$ 的独立集。
  - 若图有大小 $k$ 的独立集，由于每个子句最多选一个、共有 $k$ 个子句，所以每个子句恰好选一个。把选中的文字赋值为真；由于没有互补文字同时被选，这个赋值不会矛盾；每个子句都有一个选中的真文字，因此公式可满足。
- **规模**：$3k$ 个顶点，$3k$ 条子句内边 + $O(k^2)$ 条跨子句边，构造多项式时间。因此 IS 是 NPC。

小例子：$\varphi=(x_1\lor x_2\lor\neg x_3)\land(\neg x_1\lor x_2\lor x_3)$。取两个子句中的 $x_2$ 顶点，它们不互补，可以同时选，得到大小 2 的独立集；对应赋值 $x_2=1$，两个子句都满足。也可选 $x_1$ 与 $x_3$，对应 $x_1=x_3=1$。

### 6.4 从独立集到顶点覆盖

- **顶点覆盖问题**（vertex cover, VC）：给定图 $G=(V,E)$ 与整数 $K$，问是否存在大小 $K$ 的顶点子集 $C\subseteq V$，使每条边至少有一个端点在 $C$ 中。
- **关键等价**：$S$ 是 $G$ 的独立集，当且仅当 $V\setminus S$ 是 $G$ 的顶点覆盖。
  - 若 $S$ 独立，则对任意边 $(u,v)$，不可能 $u,v$ 同在 $S$ 中，所以至少一个端点在 $V\setminus S$ 中；
  - 若 $C=V\setminus S$ 是顶点覆盖，则 $S$ 内任意两点之间不可能有边，否则这条边两端都不在 $C$ 中，矛盾。
- 因此：$G$ 有大小 $K$ 的独立集 $\iff$ $G$ 有大小 $|V|-K$ 的顶点覆盖。
- **第一步：VC $\in$ NP**。证书取 $C$；验证 $|C|=K$，并检查每条边至少一个端点在 $C$ 中，$O(|E|)$ 时间。
- **第二步：IS $\le_P$ VC**。对任意 IS 实例 $(G,K)$，输出 $(G,|V|-K)$。由上面的等价，答案完全相同；构造是 $O(1)$（只做减法）。所以 VC 是 NPC。

### 6.5 团问题与补图

- **团问题**（clique problem）：给定图 $G=(V,E)$ 与整数 $K$，问是否存在 $K$ 个顶点，使它们两两相邻（完全子图）。
- **补图**（complement graph）$\overline G$：顶点集相同，边集取补。
- **关系**：$G$ 中的团就是 $\overline G$ 中的独立集；因此团问题与独立集问题通过补图互相归约。
- **团 $\le_P$ 顶点覆盖**：$G$ 有大小 $K$ 的团 $\iff$ $\overline G$ 有大小 $|V|-K$ 的顶点覆盖。
  - 正向：若 $V'$ 是 $G$ 的团，则对 $\overline G$ 的任意边 $(u,v)$，$u,v$ 不可能同在 $V'$ 中（否则它们在 $G$ 中应相邻，矛盾），所以 $V\setminus V'$ 覆盖 $\overline G$ 的所有边；
  - 反向：若 $V'$ 是 $\overline G$ 的大小 $|V|-K$ 的顶点覆盖，则 $V\setminus V'$ 内任意两点在 $\overline G$ 中无边，即在 $G$ 中有边，所以 $V\setminus V'$ 是大小为 $K$ 的团。
- 这个证明和 6.4 的“独立集 ↔ 顶点覆盖”是同一套补集论证，只是先过了补图。

| 问题 | 归属 | 备注 |
|---|---|---|
| SAT、3-SAT | NPC | 归约的常用起点 |
| 团、独立集、顶点覆盖 | NPC | 三者通过补图/补集紧密联系 |
| 哈密顿回路、哈密顿路径 | NPC | TSP 归约的起点 |

## 7. 高频题型与易错点

### 7.1 高频判断 / 选择

| 命题 | 判断 | 理由 |
|---|---|---|
| NP-hard 问题都是 NP 问题 | ✗ | NP-hard 不要求在 NP；停机问题是 NP-hard 但不可判定 |
| NP-complete 问题都是 NP-hard | ✓ | NPC = NP ∩ NP-hard |
| 停机问题是 NP-complete | ✗ | 它不可判定，不属于 NP |
| 某个 NP 问题有多项式算法 $\Rightarrow P=NP$ | ✗ | 这个问题可能只是 P 中的容易问题 |
| 某个 NP-hard 问题有多项式算法 $\Rightarrow P=NP$ | ✓ | 所有 NP 问题都能归约到它 |
| $Q\in NP$，SAT 有多项式算法 $\Rightarrow Q$ 有多项式算法 | ✓ | $Q\le_P SAT$ |
| $Q\in NP$，$Q$ 有多项式算法 $\Rightarrow$ SAT 有多项式算法 | ✗ | 只知道 $Q$ 容易，不能反推 SAT 容易 |
| $Q$ 是 NP-hard 且 $Q\in NP$ $\Rightarrow Q$ 是 NPC | ✓ | NPC 的定义 |
| $Q$ 是 NP-hard $\Rightarrow Q$ 是 NPC | ✗ | 还缺 $Q\in NP$ |
| $A$ 是 NPC，$B\le_P A$ $\Rightarrow B$ 是 NPC | ✗ | 只知 $B$ 不比 $A$ 难；$B$ 可能只是 P |
| $P=NP\Rightarrow NP=co\text{-}NP$ | ✓ | P 对补封闭 |
| 所有可判定问题都在 NP 中 | ✗ | NP 要求多项式长证书；可判定问题可以难到超出 NP |
| NP 就是“非多项式”或“指数时间” | ✗ | NP 是 nondeterministic polynomial time；所有 NP 问题都可判定 |
| 所有 NP 问题都可判定 | ✓ | 枚举多项式长证书即可，最坏指数时间 |

### 7.2 证明题失分点

- **方向反了**：把待证问题归约到已知 NPC，只能说明待证问题不比 NPC 难；要证 NPC，必须把已知 NPC 归约到待证问题。
- **漏证 $X\in NP$**：只写归约，结论只能是 NP-hard。
- **证书不合法**：证书长度必须多项式；验证算法必须多项式时间。
- **只证一个方向**：归约要求双向等价。
- **构造规模爆炸**：例如把指数多个子句/顶点放进输出，就不是多项式归约。
- **把 co-NP 例子说成“已知不在 NP”**：NO-HAMILTON 属于 co-NP，是否属于 NP 未知。
- **把停机问题说成 NPC**：它是不可判定问题，不在 NP。
- **把最长路和 Floyd 取反混为一谈**：正权回路取反后是负权回路，最短路无界；简单路径约束不能靠取反保留。

### 7.3 考场检查清单

证明 NPC 时按下面顺序检查：

1. 问题是不是判定问题？若是优化问题，先写它的判定版。
2. $X\in NP$ 的证书是什么？验证要多久？
3. 从哪个已知 NPC 问题归约？方向对不对？
4. 构造是否多项式？输出规模是否多项式？
5. “是”和“否”两个方向都证了吗？
6. 有没有把“某个最优解”写成“所有最优解”？
7. 结论是 NPC 还是仅 NP-hard？有没有漏掉“属于 NP”？
