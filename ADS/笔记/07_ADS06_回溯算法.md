## 1. 一页速览

| 问题 | 讲义给的答案 |
|---|---|
| 基本想法 | 有部分解（partial solution） $(x_1,\dots,x_i)$，尝试加入 $x_{i+1}\in S_{i+1}$；满足约束（constraint）就继续，否则**删除（deletion）并回退**（backtrack）——即**剪枝（pruning）** |
| 目标 | 不显式检查全部候选解，但仍保证（跑到底就）能找到答案 |
| 前提 | 候选解集合有限、解可以在有限步内判定、候选不太多 |
| 三个例子 | 八皇后、收费站重建（Turnpike Reconstruction）、井字棋（博弈 + $\alpha$-$\beta$ 剪枝） |
| 复杂度 | 与本讲的三个因素相关：$S$ 的规模、约束函数的复杂度、满足约束的结点数 |

## 2. 核心框架

### 2.1 通用模板【讲义】

```c
bool Backtracking ( int i )
{   Found = false;
    if ( i > N ) return true;                 /* solved with (x1, …, xN) */
    for ( each xi ∈ Si ) {
        OK = Check((x1, …, xi), R );          /* pruning */
        if ( OK ) {
            Count xi in;
            Found = Backtracking( i+1 );
            if ( !Found ) Undo( i );          /* recover to (x1, …, xi-1) */
        }
        if ( Found ) break;
    }
    return Found;
}
```

三个要素：**解的表示**（$x_i$ 取什么）、**约束/剪枝函数 `Check`**（决定效率）、**撤销（undo） `Undo`**（保持状态可回退）。

【讲义】另外提示：当不同 $S_i$ 的大小差异较大时，**先试规模小的 $S_i$**。

### 2.2 八皇后（Eight Queens）

- 问题：在 $8\times8$ 棋盘放 8 个皇后，任意两个不能同行、同列、同对角线（diagonal）。
- 解的表示【讲义】：$x_i$ = 第 $i$ 行皇后所在的列号（$1\le x_i\le 8$）。
- 约束【讲义】：
  1. $S_i=\{1,\dots,8\}$ ⇒ 朴素解空间（solution space） $8^8$；
  2. $x_i\neq x_j\ (i\neq j)$ ⇒ 解是 $1..8$ 的**排列（permutation）**，解空间降到 $8!$；
  3. $(x_i-x_j)/(i-j)\neq\pm1$（不同对角线）。
- 【讲义】给出一组解：$(4,6,8,2,7,1,3,5)$；对 $n$ 皇后，候选数为 $n!$。

### 2.3 收费站重建问题（Turnpike Reconstruction）

- 已知 $N$ 个点的两两距离共 $N(N-1)/2$ 个，恢复点集坐标（设 $x_1=0$）。
- 【讲义】例子：$D=\{1,2,2,2,3,3,3,4,5,5,5,6,7,8,10\}$
  - 第一步：$N(N-1)/2=15\Rightarrow N=6$；
  - 第二步：$x_1=0$，$x_6=\max D=10$；
  - 第三步：反复取当前最大距离，**两个分支（branch）**——
    - 选项 1：$X[\text{right}]=D_{\max}$；
    - 选项 2：$X[\text{left}]=X[N]-D_{\max}$；
    - 每次都用 `Check` 判断"新点与已知点的距离是否都能在 $D$ 中找到"（不清空 $D$ 就剪枝），失败则**把删掉的距离重新插回**（`Insert`）再试另一个分支；
  - 结果：$(0,3,5,6,8,10)$。

对应的讲义伪代码就是"选一个分支 → 删除相关距离 → 递归（recursion） → 失败则回填"的循环。

### 2.4 博弈：井字棋（tic-tac-toe）与 $\alpha$-$\beta$ 剪枝

- 井字棋的状态数【讲义】：$3^9=19{,}683$ 种局面，$9!=362{,}880$ 种下棋序列。
  > 研习室勘误（p.13）：$3^9=19{,}683$ 只是**格子的标记方式数**，其中包括轮流落子、胜负即止等规则不允许的局面；
  > $9!$ 也不能直接解释为全部合法完整对局数。该站把它当作"搜索规模"的示意，而不是合法局面/对局的精确计数。
- **Minimax 策略**：人试图把局面价值降到最小，计算机试图最大；用评价函数（讲义给的是"潜在获胜线数 $W$"）量化局面的好坏。
- **$\alpha$ 剪枝**：在 max 层若某分支已能保证一个不差于已知下界（lower bound）的值，则**其余的 min 子分支不必再看**；
  **$\beta$ 剪枝**：在 min 层对称地剪掉多余分支；
  **$\alpha$-$\beta$ 剪枝**：两者结合，实际把搜索规模从 $N$ 降到约 $O(\sqrt{N})$ 个节点（node），从而"允许我们搜得更深"。
- 【讲义】的引子问题：*Games – how did AlphaGo win?*

## 3. 效率由什么决定（讲义备注）

- 回溯的效率与三个因素相关：
  1. **$S$ 的规模**；
  2. **约束函数 `Check` 的复杂度**——它决定剪枝的效率，但函数本身太复杂也未必划算；
  3. **满足约束条件的结点数**——这一项最难估计，**所以回溯算法的复杂度分析通常很难做完整**。
- 讲义另有一句要点：*No tree is actually constructed. The game tree is just an abstract concept.*（游戏树只是概念，不会真的建树。）

## 4. 讲义中的例子（课上会看到）

- 4 皇后 / 8 皇后的游戏树（game tree）与深度优先（**后序遍历**）过程；
- 收费站重建的**分支回退**全过程（$x_2=4$ 失败后改 $x_3=4$ 等）；
- 井字棋的 minimax 数值标注与 $\alpha$/$\beta$ 剪枝各一页。

## 5. 听课重点与易混点

1. **"剪枝"发生在 `Check`**：一旦部分解不满足约束，整棵子树（subtree）都不用看——这是回溯比穷举（brute force）快的原因。
2. **`Undo` 必须与"做选择时修改的状态"严格对称**（收费站问题里是距离集合的删除/回插）。
3. **解空间要先压缩**（八皇后用"不同列 ⇒ 排列"把 $8^8$ 压成 $8!$），这是回溯的第一生产力。
4. **$\alpha$ 剪枝作用于 max 层、$\beta$ 剪枝作用于 min 层**，别记反。
5. 回溯是**深度优先（depth-first search）**，不是广度优先（breadth-first search）；讲义强调"后序遍历（postorder traversal）"即此意。
