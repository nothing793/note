## 2. 概率（probability）记号复习（【讲义】A Quick Review）

- $\Pr[A]$：事件 $A$ 的概率；$\overline{A}$：$A$ 不发生；
- $E[X]$：随机变量 $X$ 的期望（"平均值"）。

## 3. 雇佣问题（The Hiring Problem）

**设定**【讲义】：从猎头那里招一名助理，**每天面试一个人共 $N$ 天**；面试成本 $C_i\ll$ 雇佣成本 $C_h$；分析"面试 + 雇佣"的**总成本**而非运行时间。设最终雇了 $M$ 个人，则总成本

$$\text{Total}=N\cdot C_i+M\cdot C_h \tag{1}$$

### 3.1 朴素解法的坏情况

```c
int Hiring ( EventType C[ ], int N )
{   /* candidate 0 是最差的"哨兵" */
    int Best = 0;  int BestQ = the quality of candidate 0;
    for ( i = 1; i <= N; i++ ) {
        Qi = interview( i );                    /* Ci */
        if ( Qi > BestQ ) { BestQ = Qi; Best = i; hire( i ); }   /* Ch */
    }
    return Best;
}
```

**最坏情况（worst case）**：候选人质量**递增**到来 ⇒ 每次都要雇佣，雇佣成本 $N\cdot C_h$。

### 3.2 随机到达顺序下的期望

- 假设候选人**随机顺序**到达。记 $X$ = 雇佣次数，用指示变量（indicator random variable） $X_i=[\text{第 } i \text{ 个人被雇佣}]$；
- **随机性假设**：前 $i$ 个人中任何一个是"迄今最好"的概率相同 ⇒ $\Pr[X_i=1]=\dfrac1i$；
- 期望次数就是**调和数（harmonic number）**：

$$E[X]=\sum_{i=1}^{N}\frac1i=H_N\approx\ln N+O(1) \tag{2}$$

### 3.3 随机化版本：先把顺序打乱

`RandomizedHiring` 与上面唯一的区别是**在循环前随机置换（random permutation）候选人列表**——于是"候选人随机到达"这个假设**不再需要**，代价是置换本身的时间（$O(N)$）。

**随机排列（random permutation）的算法**【讲义】：

```c
void PermuteBySorting ( ElemType A[ ], int N )
{   for ( i = 1; i <= N; i++ ) A[i].P = 1 + rand() % (N*N*N);   /* 让优先级尽量互不相同 */
    Sort A, using P as the sort keys;
}
```

> **Claim**：在优先级互不相同的前提下，`PermuteBySorting` 产生**均匀随机**的排列。

### 3.4 在线雇佣（Online Hiring，只雇一次）

场景：必须在**当场**决定雇不雇，不能回头看。策略【讲义】：先面试前 $k$ 个人只做记录（不雇），此后**遇到第一个比前 $k$ 个都强的人就雇**。

```c
int OnlineHiring ( EventType C[ ], int N, int k )
{   int Best = N;  int BestQ = -∞;
    for ( i = 1; i <= k; i++ ) { Qi = interview( i ); if ( Qi > BestQ ) BestQ = Qi; }
    for ( i = k+1; i <= N; i++ ) {
        Qi = interview( i );
        if ( Qi > BestQ ) { Best = i; break; }
    }
    return Best;
}
```

- 记 $S_i$ = 第 $i$ 个人是最好的。要 $S_i$ 成立，需要**两个独立（independence）事件**同时发生：
  - $A$：最好的人恰好在位置 $i$（概率 $1/N$）；
  - $B$：位置 $k+1$ 到 $i-1$ 上的人都没有被雇佣（概率 $k/(i-1)$——因为前 $i-1$ 个人中的"最好者"必须落在前 $k$ 人里）。
- 于是

$$\Pr[S_i]=\frac1N\cdot\frac{k}{i-1},\qquad
\Pr[\text{雇到最好的人}]=\sum_{i=k+1}^{N}\Pr[S_i]\approx\frac kN\ln\frac Nk \tag{3}$$

- 【讲义】把"$\Pr$ 的最大值是多少、最佳 $k$ 取多少"留成 *Discussion 19*。经典结论是：$k=N/e$ 时取得最大值 $1/e\approx36.8\%$（**该结论在讲义中作为讨论题给出**）。

## 4. 随机化快速排序（randomized quicksort）

- **确定性（deterministic）快排**：最坏 $\Theta(N^2)$；在"每个输入排列等可能"的假设下平均 $\Theta(N\log N)$。
- 改进【讲义】：**均匀随机地选枢轴（pivot）**。
  - **central splitter（中心分割元）**：划分（partition）后**每一侧至少含 $n/4$ 个元素**的枢轴；
  - **Modified Quicksort**：每次递归（recursion）前**反复随机选枢轴，直到选到 central splitter**。
- 关键概率：随机选到 central splitter 的概率 $=\dfrac12$，于是**期望迭代（iteration）次数 $\le2$**（几何分布的期望）。
- 复杂度分析【讲义】的思路：把子问题（subproblem）按规模分类——称规模为 $|S|$ 的子问题属于 **type $j$** 若
  $$n\left(\tfrac34\right)^{j+1}\le |S|\le n\left(\tfrac34\right)^{j}$$
  类型总数为 $\log_{4/3}n$，且每一类型中"同一层的子问题"数量有上界（讲义给出 *Claim: There are at most … subproblems of type j*）。由此得到期望 $O(N\log N)$。
- 顺带一提：讲义的 Research Project 6 是 **Skip List**（期望 $O(\log N)$ 的查找/插入）。

## 5. 听课重点与易混点

1. **平均情况分析 vs 随机化算法**：前者假设"输入随机"（世界随机），后者让**算法自己做随机决策**（对最坏输入也有效）——这是本讲最核心的一条区分。
2. **指示变量法**：$X=\sum X_i$，$E[X]=\sum\Pr[X_i=1]$；雇佣问题里 $\Pr[X_i=1]=1/i$ 依赖于"随机到达"假设。
3. **随机置换的两种方式**：给随机优先级排序（`PermuteBySorting`）或 Fisher-Yates 式交换（讲义只讲了前者）；随机化版本**不再依赖"输入随机"**。
4. **在线雇佣的"两个独立事件"**：$A\cap B$ 独立才能相乘，这是推导式 (3) 的关键。
5. **随机化快排的"期望"**：中枢概率 $1/2$ ⇒ 期望 2 次尝试；分析要按"规模类型"分层做，而不是简单地乘一个常数。
