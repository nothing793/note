# ADS（高级数据结构和算法分析）

> 浙江大学「高级数据结构和算法分析」（Advanced Data Structures and Algorithm Analysis，主讲：陈昊）课程资料与整理笔记的工作目录。
> 本文件是 ADS 目录的入口；笔记内容从 [`笔记/00_索引.md`](笔记/00_索引.md) 开始读，写作与资料口径以 [`AGENTS.md`](AGENTS.md) 为准。
> 最近更新：2026-10-25

## 2. 阅读顺序

1. 先读 [`笔记/00_索引.md`](笔记/00_索引.md) 的「怎么用这份笔记」与文件列表；
2. 按讲义顺序读 `01`–`16`；第 8–16 讲属于算法设计技术，可按课堂进度单读；
3. 每篇按「一页速览 → 核心概念 → 关键公式与算法 → 例子 → 听课重点与易混点 → 课前自测 / 课后回顾 → 关联知识点 → 来源」使用；
4. 需要核对原文时再打开 `Materials/Student Slides/` 中对应课件，不要直接改原件。

## 3. 内容口径

- **主标准**：课程课件 + 站外参考「ADS · 算法研习室」（URL 与使用方式见 [`AGENTS.md`](AGENTS.md) §4 和 [`笔记/00_索引.md`](笔记/00_索引.md)）。
- **补充材料**：教材、拓展阅读、配套代码。与主标准冲突时以主标准为准，并注明补充材料的口径。
- 术语首次出现时写 `中文（English）`；代码块、公式、文件路径与讲义英文原话不强行翻译。
- 引用课件写 `【讲义】` 与页码 `(p.x)`；研习室结论写「（研习室）」；不确定处标 `待确认`，不编造公式、页码或结论。
- 课件勘误不改原课件，只在笔记中另起 `> 研习室勘误（p.x）：……` 注记。

## 4. 新增或修改笔记

1. 在 `笔记/` 下编辑 Markdown；配图放 `笔记/assets/`，用相对路径引用。
2. 生成配图的脚本与图片同名族放在 `笔记/assets/`，保证能重跑复现。
3. 同步更新 [`笔记/00_索引.md`](笔记/00_索引.md) 的文件列表、配图清单、对照进度与待确认事项。
4. 新增、改名或调整标题后，同步 [`../网站/mkdocs.yml`](../网站/mkdocs.yml) 的 `nav`。
5. 按下一节命令自检；只有自检通过后才算交付。

## 5. 自检与预览

在仓库根目录执行：

```bash
python3 ADS/assets/check_md_links.py ADS     # 相对路径能否打开
python3 ADS/assets/check_md_anchors.py ADS   # 标题锚点能否指到
python3 网站/build.py                         # 汇集 → 构建 → 站点自检
python3 网站/build.py -s                      # 本地预览 http://127.0.0.1:8000
```

`网站/.docs/`、`网站/site/`、`网站/.cache/` 都是生成目录，**不要直接修改**；要改内容就改 `笔记/` 原件。

## 6. 发布与版本控制

- 站点只发布 `笔记/` 下的 Markdown、配图与可复现脚本；`README.md` 与 `tasks.md` 不发布。
- `Materials/`、`期中/`、`期末/` 中的 PDF / PPT / HTML / 压缩包等原件不发布，也不在整理过程中改写、移动或改名。
- 仓库采用白名单式 `.gitignore`：Markdown 与图片默认放行，`ADS/assets/*.py`、`ADS/笔记/assets/*.py` 是显式例外；原始资料、缓存和构建产物不入库。
- 提交前请按仓库根目录的 `README.md` 与上级 `AGENTS.md` 核对入库范围。
