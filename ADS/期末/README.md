## 1. 结论

- 去重（deduplication）后共 **322 题**：判断题（true/false）126、选择题（multiple choice）178、程序填空（fill-in-the-blank）9、函数或编程（function/programming）9。
- 按原始题频，数据结构（data structure）题仍不少，因为旧期末会回炉 AVL 树（AVL tree）、伸展树（splay tree）、红黑树（red-black tree）、B+ 树（B+ tree）、左式堆（leftist heap）、斜堆（skew heap）和二项队列（binomial queue）。按“期末偏算法分析”的规则施加阶段系数（phase factor）后，排序变为：
  **NP 完全性（NP-completeness）10.2%、递推式（recurrence）8.4%、随机化算法（randomized algorithm）8.3%、贪心算法（greedy algorithm）7.4%、近似算法（approximation algorithm）6.9%、外部排序（external sorting）6.7%、局部搜索（local search）6.6%、并行算法（parallel algorithm）6.4%、动态规划（dynamic programming）5.5%。**
- 程序题的任务比期中还固定：程序填空集中在二项队列（binomial queue）6 题、红黑树 2 题、B+ 树 1 题；函数题集中在 DP 6 题、AVL 插入 2 题、快速幂（quick power）1 题。
- 期末复习应以算法设计与分析为主线，数据结构部分只做“操作手算 + 程序填空”的快速回炉。不要因为左式堆、二项队列的原始题数多，就把期末笔记写成期中结构专题的翻版。

## 3. 权重模型

单题权重（weight）按

$$
W = R \times V \times T \times P
$$

计算，再把同一知识点的 $W$ 相加并归一化到百分比。每题只记一个**主知识点（primary topic）**；同一题里的交叉内容不重复计权，避免一道综合题把多个章节同时抬高。$R$ 是年份系数（recency factor），$V$ 是变体系数（variant factor），$T$ 是题型系数（question-type factor），$P$ 是阶段系数（phase factor）。

### 3.1 年份系数

| 年份 | $R$ | 说明 |
|---|---:|---|
| 2015 | 1.0 | 最旧 |
| 2016 | 1.2 | 旧题 |
| 2017 | 1.5 | 旧题 |
| 2018 | 1.8 | 参考价值较高 |
| 2019 | 2.1 | 近年题 |
| 2020 | 2.5 | 最新期末样本 |

### 3.2 题型系数

| 题型 | $T$ | 原因 |
|---|---:|---|
| 判断 | 0.8 | 单点判断 |
| 选择 | 1.0 | 基准 |
| 程序填空 | 1.3 | 要求还原操作 |
| 函数或编程 | 1.5 | 最能检验完整实现 |

### 3.3 阶段系数

期末题横跨旧大纲，若只按原始题频，数据结构会挤占算法分析的篇幅。阶段系数把“期末应重点复习的内容”单独抬起：

| 类别 | 知识点 | $P$ |
|---|---|---:|
| 算法分析核心 | NP、近似、局部搜索、随机化、并行 | 1.20–1.30 |
| 算法设计 | 递推式、DP、贪心、外部排序 | 1.15–1.25 |
| 回溯与结构回炉 | 回溯、摊还分析 | 0.90 |
| 数据结构回炉 | AVL、伸展树、红黑树、B+ 树、左式堆、斜堆、二项队列 | 0.65 |
| 检索应用 | 倒排索引 | 0.55 |
| 基础结构 | 链表、排序数组等 | 0.80 |

具体取值可在本表基础上按课堂强调微调；不要在没有依据时改动整张表。

## 6. 高频题眼

### 6.1 算法设计与分析

- **NP 完全性**：P、NP、co-NP 的包含关系；NP 完全的两条定义；归约方向；SAT / 3-SAT / 顶点覆盖（vertex cover）/ 团（clique）/ 旅行商（TSP）/ 停机问题（halting problem）的归属；给一个语言在 NP 中，判断哪些命题必然成立。
- **近似算法**：近似比（approximation ratio）的定义；PTAS 与 FPTAS 的区别；装箱（bin packing）的 Next Fit / First Fit；$K$-中心（$K$-center）的 2-近似；背包（knapsack）的缩放；最小度生成树（minimum-degree spanning tree）。
- **随机化算法**：期望的线性性；指示器随机变量（indicator random variable）；随机化雇佣（hiring）；随机化快速排序（randomized quicksort）；MAX-3SAT 的 $7k/8$ 下界；球与盒（balls and boxes）；随机跳表（skip list）的期望代价。
- **贪心算法**：活动选择（activity selection）的交换论证（exchange argument）；Huffman 编码的前缀码（prefix code）、平均码长、最优性；硬币找零何时贪心失效；集合覆盖（set cover）的贪心近似。
- **外部排序**：生成 run、$k$ 路归并、趟数 $1+\lceil\log_k R\rceil$、多相归并（polyphase merge）、置换选择（replacement selection）、输入/输出缓冲区（buffer）。
- **局部搜索**：邻域（neighborhood）、局部最优与全局最优；Metropolis 与模拟退火（simulated annealing）；最大割（max-cut）的状态翻转；顶点覆盖与负载均衡（load balancing）；Kernighan–Lin。
- **并行算法**：PRAM、Work-Depth 模型、$W/p+T$ 界；求和、前缀和（prefix sums）、并行归并的 $RANK$；最大值查找（maximum finding）的工作量与时间。
- **递推式**：主方法（master theorem）三种情形与正则性条件（regularity condition）；递归树（recursion tree）；代入法（substitution method）；$T(n)=2T(\sqrt n)+\log n$ 的变量代换；两个有序数组的第 $k$ 小元（selection）。
- **DP**：最优二叉搜索树（optimal binary search tree）的填表顺序；切杆（rod cutting）；最长递增子序列（LIS）；解码计数；序列匹配与状态压缩。期末的程序题常把 DP 包装成新故事，先写状态定义再写转移。

### 6.2 结构回炉

- **AVL**：插入后的旋转、删除后的再平衡、节点数-高度下界、`AVL Tree Insertion`。
- **红黑树**：三节点红黑树的形状计数、删除后的颜色与旋转、`IsRBTree`。
- **伸展树**：连续访问后的树形、删除/合并、势函数与摊还界。
- **B+ 树**：阶 3 的插入分裂、`FindKey`、内部节点只做索引。
- **左式堆与斜堆**：归并路径、$Npl$、heavy/light 分析、`DeleteMin`。
- **二项队列**：森林表示、DeleteMin、Merge/Find/DeleteRoot、势函数变化。
- **倒排索引**：precision、recall、F-score；文档分区与词项分区；停用词与词干化。

## 8. 写笔记时怎么用

1. 先读第 5 节。`加权占比` 是期末复习的篇幅参考，不是题数排行榜；同一知识点在不同年份重复出现时，年份系数会把它抬高。
2. 占比 **≥7%** 的知识点，复习笔记给完整定义、关键证明思路、两个典型例子和至少一道变式。NP、递推式、随机化、贪心属于这一档。
3. 占比 **4%–7%** 的知识点，给核心结论、一个例子和易错点；近似、外部排序、局部搜索、并行、DP、二项队列、左式堆、回溯按这一档处理。
4. 占比 **<4%** 的知识点，保留速览、图表和跨讲链接；AVL、红黑树、伸展树、B+ 树、摊还分析、倒排索引不再重写长证明，但程序填空和手算要保留。
5. 期末的程序题以二项队列、红黑树、B+ 树、DP、AVL、快速幂为主。对应笔记至少要有一段“照着代码走一遍”的内容，不能只写复杂度。
6. 结构题虽然被阶段系数压低，仍会以判断、选择和程序填空出现。复习时用“操作 + 性质 + 一个反例”的方式过一遍，不占算法分析的主篇幅。
