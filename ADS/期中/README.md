## 1. 结论

- 去重（deduplication）后共 **184 题**：判断题（true/false）86、选择题（multiple choice）83、程序填空（fill-in-the-blank）11、函数或编程（function/programming）4。
- 本学期期中范围到动态规划（dynamic programming）为止。按这条线，**174 题在范围内**；另有 10 题属于旧大纲的贪心算法（greedy algorithm）或 NP 完全性（NP-completeness），只在附录标明，不进入篇幅预算。
- 范围内加权占比最高的知识点是：AVL 树（AVL tree）12.3%、二项队列（binomial queue）9.8%、伸展树（splay tree）9.5%、回溯（backtracking）9.5%、B+ 树（B+ tree）9.4%、左式堆与斜堆（leftist heap / skew heap）9.3%、递推式（recurrence）9.3%、动态规划 8.7%、红黑树（red-black tree）8.4%、倒排索引（inverted index）7.5%、摊还分析（amortized analysis）6.4%。
- 结构类题目仍占大头，约 72%；回溯、递推式、DP 合计约 28%。复习时不要把期中写成“算法设计专题”，大部分篇幅应落在数据结构（data structure）的操作、性质和手算上。
- **陈昊老师 2025 年题**的方向更集中：21 题中回溯与 DP 各占 15.8%，递推式 9.2%，其余主要是 AVL、伸展树、红黑树、B+ 树、左式堆、二项队列、摊还分析与倒排索引。它没有出现贪心题，和“范围到 DP 为止”一致。
- **2026 实考**（21 题，随机卷）的题面、得分与错题见 §1.1。主题分布与上表大体一致，但 DP 在这份卷子里占 24/100 分，是最大的一块；下一次复习不能再把 DP 当成“7%–9% 的一档”轻轻带过。

## 3. 权重模型

单题权重（weight）按

$$
W = R \times V \times T
$$

计算，再把同一知识点的 $W$ 相加并归一化到百分比。每题只记一个**主知识点（primary topic）**；同一题里的交叉内容不重复计权，避免一道综合题把多个章节同时抬高。$R$ 是年份系数（recency factor），$V$ 是变体系数（variant factor），$T$ 是题型系数（question-type factor）。

### 3.1 年份系数

| 年份 | $R$ | 说明 |
|---|---:|---|
| 2015 | 1.0 | 旧题，只用来找重复考点 |
| 2017 | 1.3 | 旧题 |
| 2018 | 1.7 | 旧题，但题型接近现在 |
| 2020 | 2.1 | 参考价值较高 |
| 2021 | 2.5 | 参考价值较高 |
| 2025（非陈昊） | 3.5 | 近年题 |
| 2025（陈昊） | 4.5 | 按你的要求单独调高 |
| 年份待确认 | 3.5 | 仅 `ADS_midterm`，暂按 2025 同级处理 |

### 3.2 题型系数

| 题型 | $T$ | 原因 |
|---|---:|---|
| 判断 | 0.8 | 只考一个判断，信息量小 |
| 选择 | 1.0 | 基准 |
| 程序填空 | 1.3 | 要能还原操作过程 |
| 函数或编程 | 1.5 | 最能暴露是否真正掌握结构 |

### 3.3 变体与重复

- 同一份试卷的重复导出只计一次；答案版、截图版不另计。
- A/B 卷或同一年的不同变体若题目不同，按两份题面分别分类，但用 $V=0.5$ 抵消同年的重复覆盖。期中这次没有需要拆分的 A/B 卷，$V$ 全为 1。
- 同一考点在不同年份反复出现时，不合并题次；年份系数会自然把新题推高。

## 6. 高频题眼

### 6.1 结构操作

- **AVL 树**：给节点数求最大/最小高度；判断平衡因子（balance factor）组合是否可能；LL / RR / LR / RL 旋转后谁是根、谁是谁的孩子；删除后是否仍平衡；`IsBalanced` 的返回值与高度回填。
- **伸展树**：连续访问两三个键后画树；访问最小值/最大值后根缺少哪一侧子树；删除后的前驱/后继作根；合并多棵伸展树时的摊还界。
- **红黑树**：五条性质、黑高（black height）、插入/删除后的颜色与旋转、删除旋转次数是否为 $O(1)$、`IsRBTree` 检查。
- **B+ 树与 2-3 树**：阶为 $m$ 时根/内部节点的孩子数与键数；插入分裂、删除借位/合并；给定阶 3 和一组键，判断节点数、根中键、叶节点内容。
- **左式堆与斜堆**：$Npl$ 定义与归并结果；右路径（right path）长度；BuildHeap 的代价；DeleteMin 后谁作根；斜堆“总是交换”和 heavy/light 摊还分析。
- **二项队列**：森林表示与二进制下标；$N$ 次插入的最坏/摊还代价；DeleteMin 后剩下哪些 $B_k$；`Merge`、`Find`、`DeleteRt` 的指针操作；势函数（potential function）变化。
- **摊还分析**：势能法、记账法（accounting method）、聚合分析（aggregate analysis）三者的区别；双栈队列（two-stack queue）的势函数；动态数组（dynamic array）扩容/缩容的 $O(1)$ 摊还代价。

### 6.2 应用与算法

- **倒排索引**：precision、recall、F-score 的分母；词干化（stemming）与停用词（stop word）的区别；文档分区与词项分区；散列与搜索树的取舍。
- **回溯**：4 皇后/8 皇后的搜索顺序；收费站重建（turnpike reconstruction）下一步放哪个点；$\alpha$-$\beta$ 剪枝（alpha-beta pruning）在哪个节点发生、条件是什么。
- **递推式**：主方法（master theorem）三情形与正则性条件（regularity condition）；$T(n)=9T(n/3)+O(n^2)$、$T(n)=4T(n/2)+O(n^2\log n)$、$T(n)=2T(\lfloor\sqrt n\rfloor)+\log n$；不平衡划分用递归树（recursion tree）加代入法（substitution method）。
- **DP**：最优二叉搜索树（optimal binary search tree）的填表顺序；切杆（rod cutting）的递推与复杂度；DP 与递归的区别；最长递增子序列、疲劳度调度、解码计数。

## 8. 写笔记时怎么用

1. 先读第 5 节。`加权占比` 是篇幅预算，不是“题数排行榜”。
2. 占比 **≥9%** 的知识点，复习笔记（review notes）应给完整定义、关键不变量、手算例子和至少一道程序题；AVL、二项队列、伸展树、回溯、B+ 树、左式堆/斜堆、递推式都属于这一档。
3. 占比 **7%–9%** 的知识点，给核心操作、一个典型例子和易错点；DP、红黑树、倒排索引按这一档处理，DP 还要补一道完整建模。
4. 占比 **<7%** 的知识点，保留速览与跨讲链接，不展开长证明；摊还分析仍要与伸展树、斜堆、二项队列的势函数互相引用，避免重复抄三遍。
5. 陈昊老师 2025 年卷作为主样本：回溯和 DP 的优先级要高于它们在总表里的名次；数据结构部分按 AVL、伸展树、红黑树、B+ 树、左式堆、二项队列逐个过一遍手算。
6. 旧范围的贪心与 NP 不进入期中篇幅预算。若老师临时通知范围变化，再按新通知改本表。
