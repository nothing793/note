# 2025 陈昊

## 判断题

1. **T**。距离集合 $D=\{1,2,3,4,5,6\}$ 下，$(0,2,5,6)$ 是一组解；取 $x_1=0$ 时仍有另一组解 $(0,1,4,6)$，所以不是唯一解。
2. **F**。结果根的 NPL 不是由 $\max$ 决定的。反例：$H_1$ 根只有左孩子，且左孩子的 NPL 为 1，所以 $H_1$ 根的 NPL 为 0；$H_2$ 根的 NPL 为 1。归并后根的两个孩子 NPL 都是 1，结果 NPL 为 $2=\max+1$。
3. **F**。找到最小键并把它 splay 到根后，根没有左子树；右子树可以存在。题面说“没有右子树”是反的。
4. **F**。DP 的核心是保存并复用子问题的结果，避免重复计算；题面说反了。
5. **F**。按讲义阶 3 的约定（叶子最多 3 个键、内部节点最多 2 个键），插入后根为 $[5,10]$，和为 15，不是 14。
6. **F**。20 个节点的 AVL 树高度可以是 4，也可以是 5；高度 6 至少需要 33 个节点（$N(6)=33$），所以“必须是 5”不成立。
7. **T**。二项队列的归并是 $O(\log N)$，比二叉堆的归并（$O(N)$）好。
8. **F**。标准主定理要求 $f(n)$ 与 $n^{\log_b a}$ 相差一个多项式因子；$n/\log n$ 落在主定理的缺口里。用递归树可得 $T(n)=\Theta(n\log\log n)$。
9. **T**。文档分区（document-partitioning）下，单术语查询要发给所有分片；词项分区（term-partitioning）可以只路由到一个分片。
10. **F**。删 12 后只需在 13 处左旋；变色的是 13（红→黑）、15（黑→红）、17（红→黑），14 的颜色不变。

4. **B**。splay 7 后删根，合并左右子树时：若取左子树最大 6 作根，6 是 5 的父；若取右子树最小 8 作根，6 是 5 的后代。6 不可能是 5 的祖父。

6. **B**。学习第 $i$ 个 topic 后要转到 $i+1$，且当前累计疲劳 $f$ 要计入本题用时：$dp(i+1,\ h-\text{hours}[i]-f,\ f+\text{fatigue}[i])$。
7. **C**。取 $\Phi=2n-m$（$n/m\ge1/2$）和 $\Phi=m/2-n$（$n/m<1/2$），扩容、缩容的摊还代价都是 $O(1)$。注：D 的 $|2n-m|$ 也能给出 $O(1)$ 上界，若按单选取最贴合题意的 C。
8. **B**。斜堆归并时无条件交换归并路径上每个节点的左右孩子；左式堆只在 NPL 性质被破坏时交换。

## 判断题

1. **T**。如果排序能在 $O(n)$ 时间内完成，那么先排序、再用两个队列实现 Huffman，整体就是 $O(n)$。
2. **F**。4 个节点的 AVL 树深度为 3 时，若 4 作根，左子树必须高 2、右子树为空，根 4 的平衡因子为 2，不再是 AVL。

## 多选题

1. **ABD**。A 真：退化的 Huffman 树最大码长可达 $n-1$；B 真：频率最高的符号可以只编 1 位；C 假：最优前缀码的平均码长不超过 $H+1\le \log n+1$，不可能是 $\Theta(n)$；D 真：一个符号占绝对多数时平均码长可以接近常数。

3. **ABCD**。每次把较小树中的节点插入较大树，节点所在树的大小至少翻倍，所以每个节点最多被插入 $O(\log N)$ 次；总插入次数 $O(N\log N)$；每次插入摊还 $O(\log N)$；总代价 $O(N\log^2 N)$，分摊到 $N-1$ 次合并即每次合并摊还 $O(\log^2 N)$。

## 函数题

Decode 的参考实现：

```c
int Decode( char NumStr[] )
{
    int dp[2000005];
    int l = 0, i;
    while (NumStr[l] != '\0') l++;
    dp[0] = 1;
    for (i = 1; i < l; i++) {
        dp[i] = dp[i-1] % BASE;
        char x = NumStr[i-1], y = NumStr[i];
        if (x-48 != 0 && i == 1 && (x-48)*10 + y-48 <= 25) {
            dp[i] = 2;
            continue;
        }
        if (x-48 != 0 && (x-48)*10 + y-48 <= 25)
            dp[i] = (dp[i] + dp[i-2]) % BASE;
    }
    return dp[l-1] % BASE;
}
```

思路：`dp[i]` 表示前 `i+1` 位数字的解码方案数；单独解一位继承 `dp[i-1]`，若相邻两位能组成 10–25 的合法编码，再加上 `dp[i-2]`。样例 `1213407` 输出 5。
